## 速读（TL;DR）

- 外部 host 只有两个：`fapi.binance.com`（只读行情/元数据）与 `api.gateio.ws`（Gate API v4，公开行情 + 私有实盘）。
- Binance USDⓈ-M 共 **7 个 `/fapi/v1`** 接口，全部用于实时快照或 parquet 数据集抓取，无私有/下单接口（`tests/test_external_endpoints.py:16-24`）。
- Gate 公开行情用 **4 个 path**（paper 的 3 个 + 实盘模块的 `contracts` 列表，均 `auth=False`）；Gate 私有签名接口为 **8 个 path / 9 个调用**（`orders` 同时用于 GET 与 POST）。
- 签名公式：`SIGN = HMAC_SHA512(secret, METHOD\nPATH\nQUERY\nSHA512(BODY)\nTIMESTAMP)`；请求头 `KEY`、`Timestamp`（秒，浮点字符串）、`SIGN`（`src/gridtrade/api/live_gate.py:131-137`）。
- 手续费优先取 Gate 合约返回的 `maker_fee_rate/taker_fee_rate`：四标的实测 maker `-0.000075`（-0.75bp 返佣）、taker `0.00075`（7.5bp）；资金费按 `funding_next_apply` 结算，`cash -= position×mark×rate`。
- 自动校验：`tests/test_external_endpoints.py` 扫描 4 个源文件中的 `/fapi/*`、`/futures/*` 与 host，未登记路径或未知 host 直接测试失败。
- 服务器出口访问 `fapi.binance.com` 超时（历史事实，本次未实测）；面板降级 `source="offline"`，`GRIDTRADE_PROXY` 只作用于 `LiveMarket` 的 httpx 客户端，`research/fetch.py` 不读代理。

## 6. Gate APIv4 签名算法

Gate APIv4 官方公式（原文语义）：

```
SIGN = HMAC_SHA512(secret,
         METHOD + "\n" + PATH + "\n" + QUERY + "\n" + SHA512(BODY) + "\n" + TIMESTAMP)
```

其中 `SHA512(BODY)` 是请求体字节的 SHA-512 **十六进制小写**摘要（空 body 也要对空串求摘要）。请求头携带 `KEY`、`Timestamp`、`SIGN`。

本仓库实现（`src/gridtrade/api/live_gate.py:131-154`）：

```python
payload = hashlib.sha512(body.encode("utf-8")).hexdigest()
message = f"{method}\n{path}\n{query}\n{payload}\n{timestamp}"
signature = hmac.new(secret.encode(), message.encode(), hashlib.sha512).hexdigest()
headers = {"KEY": key, "Timestamp": timestamp, "SIGN": signature}
```

| 细节 | 实现 | 代码 |
| --- | --- | --- |
| `method` | 大写 HTTP 方法（`"GET"`/`"POST"`/`"DELETE"`） | `live_gate.py:139-153` |
| `path` | 不含 host、不含 query 的路径，如 `/futures/usdt/accounts` | `live_gate.py:139-154` |
| `query` | `urlencode(sorted(params.items()))`，空参数为 `""` | `live_gate.py:148` |
| `body` | `json.dumps(body)`；无 body 时 `""` | `live_gate.py:149` |
| `timestamp` | `str(time.time())`，秒的浮点字符串 | `live_gate.py:152` |
| URL 一致性 | 实际请求 URL = `path + "?" + query`，与签名串使用同一 query | `live_gate.py:154-158` |
| 测试向量 | 固定时间 `1794900000.5`，对 `GET /futures/usdt/accounts` 空 query/body 验证 `KEY/Timestamp/SIGN` | `tests/test_live_gate.py:121-130` |
| 错误处理 | HTTP ≥400 → `LiveUpstream`；401/403 提示检查 Key/Secret 与权限 | `live_gate.py:161-170` |

- `subaccount` 字段存在于配置（`api/config.py:185`），但签名头里**没有** `X-Gate-Subaccount` 之类的传递；代码中不存在子账号请求头（`api/live_gate.py:131-158`）。

## 9. 接口合规约束与新增流程

- 约束：只调用交易所**官方公开文档**中的接口；禁止第三方聚合器、非官方镜像、未登记的 `/fapi/*` 或 `/futures/*` 路径、未知 host（`tests/test_external_endpoints.py:79-85`）。
- 新增接口流程（历史笔记，`docs/memory/07-外部接口清单与官方文档对照.md:81-85`）：
  1. 确认该接口出现在官方文档（Binance 用记忆库 catalog；Gate 用官方 APIv4 文档 + 官方 SDK）；
  2. 在本文档登记 path、用途、字段与文档链接；
  3. 在 `tests/test_external_endpoints.py` 的 `BINANCE_FAPI`/`GATE_FUTURES` 允许清单添加该 path；
  4. 用真实响应校验字段名、类型与单位，再写解析代码。
- 当前未使用的类别：Binance 私有/账户/下单接口、WebSocket 订单流、Gate 提现/划转接口。Gate 私有接口仅覆盖第 5 节列的实盘分析/下单需求。
- 安全约束：任何密钥只进 `.env`（0600）或环境变量；**本文档与示例**一律用 `<token>`/`<api-key>`/`<api-secret>` 占位，禁止写入实际值（`api/live_gate.py:8-9,83-112`）。
