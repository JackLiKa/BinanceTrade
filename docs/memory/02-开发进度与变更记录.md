## 2. 已完成功能

### 后端

- 领域模型、网格策略、OMS、模拟撮合、风控、研究运行器。
- 回放 / 前向滚动 / 参数扫描三类任务，后台线程执行、进度轮询、取消。
- SQLite 持久化（runs、artifacts、audit、settings）；WAL；启动时把遗留的排队/运行中任务标记失败。
- 认证（Bearer / X-API-Token / Cookie / WS token）；令牌自动生成。
- 数据质量（覆盖、缺口、时间戳单调性）、行情快照/K 线/资金费、风控限额、kill switch、审计。
- SPA 托管与未知路径回退。
- pytest 最近一次 **74 passed**（新增 6 个后台账号/会话/配置写入用例）。

### 前端

- 9 页全部中文化；状态、订单、审计动作等展示层映射集中在 `web/src/labels.ts` 与各页面。
- 桌面侧边栏 / 移动底部导航 + 更多抽屉两种外壳。
- 回测结果页：业绩表现、月度归因、月度表、权益/回撤/成交图（单次回放通常 14 个 canvas）。
- 命令面板（⌘K）：搜索页面/交易对/操作，Enter/点击跳转，Esc 关闭。
- 响应式与 WebView 兼容修复：`min-width: 0`、不透明 fixed 表面、lightweight-charts 时间轴留白、月度表横向滚动。
- 设置页：服务器地址、令牌、执行模式、kill switch、审计日志；退出登录。

### APK

- 单 Activity WebView 壳，包名 `com.gridtrade.panel`，versionName 0.1.0，minSdk 26 / targetSdk 34，release 签名。
- 原生中文：首次设置页（服务器地址/访问令牌/打开面板）、错误页（无法连接服务器/重试/服务器与令牌）、面板菜单（重新加载/服务器与令牌/退出登录/退出应用）。
- 返回键：有 WebView 历史则后退；历史尽头弹出原生菜单。此前 `NoActionBar` 导致菜单完全不可达，已移除无用的 ActionBar 菜单代码。
- 已开启 `WebView.setWebContentsDebuggingEnabled(true)` 便于测试（**分发前应关闭或仅 debug 构建开启**）。
- 构建不使用 Gradle：`apk/build.sh` 依次执行 aapt2 → javac 21 → d8 → zip dex → zipalign → apksigner；产物约 25KB。
- 真机安装注意：该 OPPO/OnePlus 机型直接 `adb install` 会卡在安装引导，需 `pm install-create/write/commit`。

## 5. 2026-11-17 新增功能：实时模拟盘 + APK 免登录

- `.env`：服务端从仓库根 `.env` 读取全部 `GRIDTRADE_*`（systemd `EnvironmentFile`）；
  APK 构建读取 `apk/.env` 生成 `BuildConfig`（服务器地址 + 令牌），首次启动不再要求登录。
- 组合模拟盘：Gate 永续公开行情，4 标的（SKHY/SPCX/GOOGL/AMGN）共享保证金，
  每个标的独立网格，计算 maker/taker 手续费与 8h 资金费，组合权益/持仓/成交/资金费
  持久化到 `var/paper.db`，服务重启自动恢复。
- API：`/api/paper`、`/api/paper/start|stop|reset`；前端新增第 10 页 `#/paper`。
- 单元测试：`tests/test_paper.py` 覆盖成交/手续费/已实现、资金费多空符号、止损与持久化。
- 公网验证：服务器模拟盘自动启动，真实行情下产生成交、手续费与持仓；页面启停、
  移动视口与权益图正常。
- 实盘：Gate 私有接口只读分析 + 页面配置写 `.env`；下单代码完整但默认锁定，未配置 Key 时不会发起私有写请求。
- 已知：APK 令牌编译进包，轮换令牌后需重建；真机锁屏时无法用 adb 继续 UI 验收。
- 外部接口：全部为官方公开接口，清单见 `docs/memory/07-外部接口清单与官方文档对照.md`；`tests/test_external_endpoints.py` 阻止未登记接口。
