## 1. Binance USDⓈ-M Futures（行情/元数据）

代码：`src/gridtrade/api/live.py`（实时快照）、`research/fetch.py`（数据集抓取）。
记忆库目录章节：USDⓈ-M Futures REST · 行情（`/fapi/v1`）。

- 以上 path 全部出现在记忆库 Binance catalog 的 USDⓈ-M Futures 行情章节，未使用目录外接口。

- Binance 官方文档站会 302 到新的 `/en/docs/catalog/...` 结构，上表链接为跳转后的规范地址。

## 2. Gate API v4 · USDT 永续（实时模拟盘数据源）

代码：`src/gridtrade/api/paper.py`。
官方文档：Gate API v4 · Futures（`https://www.gate.io/docs/developers/apiv4/en/#futures`）。
审计时的网络对 `www.gate.io` 文档页返回 403，因此再用官方 SDK 文档交叉验证 path 与参数：
[gateapi-nodejs · FuturesApi](https://github.com/gateio/gateapi-nodejs/blob/master/docs/FuturesApi.md)。

| 方法/路径 | 用途 | 使用的字段 | 官方文档参照 |
| --- | --- | --- | --- |
| `GET /futures/{settle}/contracts/{contract}` | 合约参数与费率 | `order_price_round`、`quanto_multiplier`、`order_size_min`、`funding_interval`、`funding_next_apply`、`maker_fee_rate`、`taker_fee_rate` | Gate API v4 · Futures · Query single contract |
| `GET /futures/{settle}/tickers` | 全量行情（客户端按合约过滤） | `contract`、`mark_price`、`index_price`、`funding_rate`、`change_percentage` | Gate API v4 · Futures · Get all futures trading statistics |
| `GET /futures/{settle}/funding_rate` | 资金费历史（结算时取最近一条） | `t`、`r`；`limit<=1000` | Gate API v4 · Futures · Futures market historical funding rate |

官方 SDK 文档中的对应条目（实测抓取）：

```
GET /futures/{settle}/contracts              Query all futures contracts
GET /futures/{settle}/contracts/{contract}   Query single contract information
GET /futures/{settle}/tickers                Get all futures trading statistics
GET /futures/{settle}/funding_rate           Futures market historical funding rate
```

`settle` 固定为 `usdt`，因为默认标的都是 USDT 本位永续。

## 3. 手续费与资金费口径

- **手续费来源**：优先使用 `contracts` 返回的 `maker_fee_rate` / `taker_fee_rate`（当前四个标的均为 maker `-0.000075`、taker `0.00075`，即挂单有 0.75bp 返佣、吃单 7.5bp 成本）。只有交易所未返回费率时，才回退 `.env` 的 `GRIDTRADE_PAPER_MAKER_FEE_BP` / `GRIDTRADE_PAPER_TAKER_FEE_BP`。可用 `GRIDTRADE_PAPER_USE_EXCHANGE_FEES=0` 强制使用配置值。
- 负费率按返佣处理：`fee = |qty| × price × rate`，`cash -= fee`；负 fee 使现金增加，成交表与汇总显示为负手续费（净返佣）。
- **资金费**：到 `funding_next_apply` 时，用 `funding_rate` 历史中与结算时刻最接近（±15 分钟）的 `r`，按 `cash -= position × mark × rate` 结算；`funding_interval` 推进下次结算时间。
- 费率与资金费都按标的记录，并在组合层汇总。

## 4. 接口合规约束

- `tests/test_external_endpoints.py`：源码出现未登记的 `/fapi/*` 或 `/futures/*` 路径、或非 `fapi.binance.com` / `api.gateio.ws` 的外部 host，测试直接失败。
- 新增接口流程：
  1. 确认它出现在官方文档（Binance 用记忆库 catalog；其他交易所用其官方 API 文档）；
  2. 在本文表格登记 path、用途、字段与文档链接；
  3. 在测试允许清单添加该 path；
  4. 用真实响应校验字段名与单位，再写解析代码。
- 不使用的类别：任何私有/下单/账户接口、WebSocket 订单流、无需鉴权的内部端点。实盘接入前必须单独审计签名、时钟同步与错误码。
