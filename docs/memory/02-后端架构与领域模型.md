## 速读（TL;DR）

- 后端是**模块化单体**：FastAPI 入口 → `api/service.py` 编排 → 纯领域层（`strategy`/`execution`/`risk`）→ `store`/`dataset` 持久化；策略层不接触任何 I/O（`src/gridtrade/ports.py:1-5`）。
- 领域模型只有 **4 个枚举 + 12 个 dataclass**；代码中**不存在** `OrderSide`、`Account`、`GridConfig`、`GridLevel` 这些名字（`src/gridtrade/domain/models.py`）。
- 网格策略用**库存层**表达：`inventory = -level*size`；`level` 由实际持仓反推，而不是自增计数（`src/gridtrade/strategy/grid.py:1-8,82-84`）。
- 回测默认**保守撮合**：上涨 bar 只成交卖单、下跌 bar 只成交买单；`intrabar=True` 只是乐观上界（`src/gridtrade/execution/simulated.py:1-12`）。
- 手续费 = `notional × (fee + slip_bp/1e4)`；资金费 = `cash -= position×mark×rate`，正费率多头付、空头收（`src/gridtrade/execution/simulated.py:44-50,160-171`）。
- 风控有**两套派生限额公式**（`default_risk_limits` 与 `risk_limits_for`），CLI/面板实际走后者；kill switch 只拦 Gate 实盘下单（`src/gridtrade/research/engine.py:60-68`、`src/gridtrade/research/runner.py:51-62`、`src/gridtrade/api/app.py:769-770`）。
- **`research/cli.py` 没有 artifact/进度/取消**；artifact、进度、取消只在 `api/{jobs,service,store}.py`，且 replay 运行期间不可取消（真正的判据是 `api/service.py:312-324` 只在 4 个进度点检查取消；`jobs.py:78-97` 是 API 侧进度回调、`cli.py:109-137` 只打印）。
- 面板模拟盘 `api/paper.py` 是**独立实现**，不复用 `Strategy/OMS/SimExecution`（`src/gridtrade/api/paper.py:1-10,200-214`）。

## 1. 分层架构与请求路径

```
浏览器 SPA / WebView APK / /admin 静态页
   │  HTTP /api/*   (Bearer | X-API-Token | gt_token Cookie)
   │  WS  /ws?token=...
   ▼
api/app.py  create_app(): 认证 / 路由 / 静态文件 / WS
   ├─ api/service.py   ResearchService：数据集缓存 + artifact 打包
   ├─ api/jobs.py      JobQueue：2 个 worker 线程 (app.py:257)
   ├─ api/store.py     Store：SQLite WAL（runs/artifacts/settings/audit）
   ├─ api/paper.py     PaperEngine + GateFeed（独立网格引擎）
   ├─ api/live_gate.py LiveService + GatePrivateClient
   ├─ api/live.py      LiveMarket：Binance 实时快照（可降级 offline）
   └─ api/admin.py     /admin 账号密码后台
   │
   │  纯 Python 调用（无 I/O）
   ▼
domain（broker 无关）
   strategy/base.py ──OrderIntent──► execution/oms.py
   strategy/grid.py                execution/simulated.py (SimExecution)
   risk/limits.py (RiskEngine / DrawdownGuard)
   ports.py (ExecutionPort / MarketDataPort / Clock)
   │
   │  数据与持久化
   ▼
research/dataset.py ◄── research/data/*.parquet
research/engine.py  ◄── runner.py ◄── cli.py / api/service.py
store: var/gridtrade.db    paper: var/paper.db    token: var/token
```

- 认证：令牌来自 `GRIDTRADE_TOKEN` 或 `var/token`（0600，`src/gridtrade/api/config.py:90-103`）；三种传递方式 + WS `?token=`（`src/gridtrade/api/app.py:321-336`）。
- WS `?token=` 校验失败时**不返回 HTTP 401，而是以 close code `4401` 关闭**；之后循环推送（`src/gridtrade/api/app.py:903-933`）。
- WS 每 3 秒推送**一条行情快照**：`{"type":"market","symbol","data","sent_at"}`，**不含任务状态**；任务状态靠前端轮询 `GET /api/runs/{id}`（`src/gridtrade/api/app.py:919-931`）。
- 纯领域层只依赖 `ports.py` 的 Protocol；交易所怪癖必须留在 adapter（`src/gridtrade/domain/models.py:1-5`）。

## 5. 网格策略

`GridParams`（frozen，`src/gridtrade/strategy/grid.py:21-27`）：

| 字段 | 类型 | 默认 | 校验/说明 |
| --- | --- | --- | --- |
| `spacing_bp` | float | `120.0` | >0，否则 `ValueError`（`grid.py:29-31`） |
| `levels` | int | `30` | >0（`grid.py:33-34`） |
| `leverage` | float | `1.0` | >0（`grid.py:34-35`） |
| `reanchor_bars` | int \| None | `None` | `0` 为假值=关闭（`grid.py:70`） |
| `group` | str | `"grid"` | 实际组名 `"{group}:{symbol}"`（`grid.py:50-51`） |

| 量 | 公式/规则 | 代码 |
| --- | --- | --- |
| `step` | `anchor × spacing_bp / 1e4` | `grid.py:106` |
| `size`（每格数量） | `equity × leverage / levels / anchor`，再 `align_qty()` 向下取整 | `grid.py:110-114` |
| `level` | `int(round(-position_qty / size))`，仅在 `on_fill` 更新 | `grid.py:82-84` |
| 卖单价 / 买单价 | `anchor+(level+1)×step` / `anchor+(level-1)×step` | `grid.py:123-144` |
| 层级钳制 | `level==levels` 不挂卖；`level==-levels` 不挂买 | `grid.py:123,134` |
| 起始锚点 | `on_start` 用 `ctx.mark_price`（引擎传 bar0.open） | `grid.py:58-60`、`engine.py:113-117` |
| 重锚（空仓） | 每 N 根 bar 用 `bar.close` 重设 anchor 并重挂 | `grid.py:70-78` |
| 重锚（有仓） | 先置 `_pending_reanchor` 并 flatten，平仓后才重设 | `grid.py:63-76` |
| 平仓单 | `MARKET + IOC + reduce_only`，tag=`flatten` | `grid.py:147-158` |
| `strategy_id` | `grid/{spacing_bp:g}bp/{levels}L/{leverage:g}x` | `grid.py:53-56` |

- 两单都 `POST_ONLY`、`reduce_only=False`（`grid.py:119-145`）；tag 形如 `lvl+1`/`lvl-1`（`grid.py:130,141`）。
- 策略**没有止损价条件**：止损由引擎 `DrawdownGuard`（`stop_dd`）或策略的“重锚前清仓”承担（`grid.py:21-27`、`engine.py:34,100-102,174-177`）。
- 状态机：未初始化（`size==0`）→ 正常运行（按 level 挂相邻两单）→ 待重锚（只发 flatten）→ 回到正常；引擎级 `ReplayEngine._halted` 后不再把成交回调给策略（`grid.py:62-87`、`engine.py:103,179-183`）。

## 6. 撮合与模拟执行

`SimFees`（`src/gridtrade/execution/simulated.py:38-50`）：`maker=0.0002`（2bp）、`taker=0.0005`（5bp）、`slip_bp=0.2`；`maker_all_in = maker + slip_bp/1e4`（默认 2.2bp），`taker_all_in` 默认 5.2bp。

| 规则 | 保守口径（`intrabar=False`，默认） | 代码 |
| --- | --- | --- |
| bar 方向 | `close >= open` 为 up（平盘算 up） | `simulated.py:187` |
| 成交方向 | up bar 只扫卖单；down bar 只扫买单 | `simulated.py:186-187,214-237` |
| 卖单触达 | `order.price <= bar.high + 1e-12`，最低卖价优先 | `simulated.py:222-226` |
| 买单触达 | `order.price >= bar.low - 1e-12`，最高买价优先 | `simulated.py:227-231` |
| 市价单 | 进待成交队列，下一根 bar 的 `open` 成交，taker 计费 | `simulated.py:103-104,201-212` |
| 成交数量 | 一次成交 = `order.remaining`，状态直接 `FILLED` | `simulated.py:239-268` |
| 单 bar 上限 | `max_fills_per_bar=2000`，超限 `truncated_bars += 1` | `simulated.py:62,216,235-236` |

`intrabar=True`（乐观上界）：up bar 先按 low 扫买单、再按 high 扫卖单；down bar 反之（`simulated.py:179-188`）。

| 费用/资金费 | 公式 | 符号 |
| --- | --- | --- |
| 手续费 | `fee = qty×price×rate`；BUY `cash -= notional+fee`，SELL `cash += notional-fee` | 绝对 USDT（`simulated.py:241-248`） |
| 资金费 | `payment = position × mark × rate`；`cash -= payment`；`funding_paid += payment` | 正费率多头付、空头收；`funding_paid>0` 为净支付（`simulated.py:160-171`） |
| 权益 | `equity = cash + position × mark` | `simulated.py:145-147` |

## 7. OMS 与订单生命周期

- client id：`"gt-" + sha1(f"{symbol}|{group}|{tag}|{generation}").hexdigest()[:16]`，19 字符；generation 按 `(group,tag)` 自增（`src/gridtrade/execution/oms.py:58-60,306-309`）。
- `sync(group, intents, ctx)`：拆分 market/limit → 校验 tag/价格/最小名义 → 取消不再声明或经济性变化的单 → keep 未变的单 → 补挂新单（先过风控）→ 处理市价单（`oms.py:103-182`）。
- `_same` 比较 side/type/tif/reduce_only/remaining/price，重复声明为 no-op（`oms.py:341-349`）。
- 对账 `reconcile(snapshot)`：本地有而 broker 无 → `UNKNOWN`；broker 有而本地无 → 记录并尝试撤单；持仓偏差 > `step_size/2` → 报告 mismatch 但不自动采纳（`oms.py:248-286`）。
- `flatten(group, ctx)`：持仓 `<= step_size/2` 返回空；否则 `MARKET+IOC+reduce_only`（`oms.py:184-197`）。

| 生命周期阶段 | 触发 | 结果 | 代码 |
| --- | --- | --- | --- |
| 生成 | `_place` | `NEW` | `oms.py:290-333` |
| 交易所拒单 | `SubmitAck.ok=False` | `REJECTED`，记录 `reason` | `oms.py:324-329` |
| 部分成交 | 收到 `Fill` 且仍有剩余 | `PARTIALLY_FILLED`，加权均价 | `oms.py:214-228` |
| 全成 | 剩余 ≤1e-9 | `FILLED` | `oms.py:224-227` |
| 撤单 | `port.cancel()` 成功 | `CANCELED` | `oms.py:335-339` |
| 对账缺失 | 本地 open、broker 无 | `UNKNOWN`（查询，不盲重试） | `oms.py:258-261` |

**拒单原因**（按来源）：OMS 规范化 `missing_tag`、`duplicate_tag`、`bad_price`、`min_notional`；提交 `exchange_reject`；风控 `qty_nonpositive`、`bad_price`、`price_deviation`、`reduce_only_flat`、`reduce_only_flip`、`max_position`、`max_order_notional`、`max_gross_notional`、`max_open_orders`、`order_rate`；模拟 adapter 另有 `post_only_would_take`、`reduce_only_invalid`（`oms.py:108-144,324-329`、`risk/limits.py:49-97`、`simulated.py:92-99`）。

## 8. 风控

`RiskLimits`：`max_position_qty`、`max_order_notional`、`max_gross_notional` 必填且 >0；`max_open_orders=200`、`max_submits_per_minute=60`、`max_price_deviation_bp=100.0`（`src/gridtrade/risk/limits.py:17-29`）。

`RiskEngine.check` 短路顺序（`risk/limits.py:37-99`）：数量>0 → 参考价>0 → 价格偏离 → reduce_only（空仓/穿越零轴拒绝，通过则**跳过后续** size/rate 检查）→ 持仓上限 → 单笔名义 → 总名义（对传入 open orders 求和）→ 挂单数 → 每分钟提交数。只有 ack 成功后才 `record_submit`（`oms.py:331`）。

| 派生限额 | 公式 | 使用方 |
| --- | --- | --- |
| `default_risk_limits(capital, first_price)` | pos=`capital×5/first_price`；order=`capital×0.5`；gross=`capital×5`；200 单；120 次/分；偏离 200bp | 直接构造 `ReplayEngine` 时（`engine.py:60-68,97`） |
| `risk_limits_for(capital, price0, params)` | size=`capital×lev/levels/price0`；pos=`size×levels×1.05`；order=`size×price0×3`；gross=`capital×lev×1.3`；挂单=`max(levels×2,10)`；120 次/分；偏离=`spacing_bp×(levels+2)×2.0` | CLI/API 的 `run_replay`（`runner.py:51-62,70-71`） |

- `DrawdownGuard(max_dd, peak=0.0, halted=False, drawdown=0.0)`：`drawdown = max(0, 1-equity/peak)`；`drawdown > max_dd`（严格大于）触发并**自锁**，halt 后不再更新峰值（`risk/limits.py:111-127`）。
- 引擎接线：`BacktestConfig.stop_dd=0.10`；触发后 `_halt` = 撤组 + 市价 flatten（`engine.py:34,100-102,135-140,174-177`）。
- kill switch：SQLite `settings.kill_switch`，仅拦截 Gate 实盘下单/平仓（409），**不拦研究/回放/paper**（`api/app.py:411,769-770,794-795,861-867`）。
- 拒单计数：无进程内累加器；面板 `/api/risk` 只从最近一次成功的 replay artifact 取 `orders.rejection_reasons`（并附派生限额与回撤状态）；`orders.counts` 只存在于 artifact 内，不被 `/api/risk` 使用（`api/app.py:845-856`、`api/service.py:505-508,558-563`）。

## 9. 研究引擎与产物

`ResearchParams`（`src/gridtrade/research/runner.py:19-30`）：`capital=10_000.0`、`spacing_bp=120.0`、`levels=30`、`leverage=0.5`、`reanchor_bars=None`、`stop_dd=0.10`、`maker_fee=0.0002`、`taker_fee=0.0005`、`slip_bp=0.2`、`intrabar=False`。

| 任务 | 输入 → 流程 | 产物（artifact） |
| --- | --- | --- |
| replay | `run_replay`: `GridStrategy` + `risk_limits_for` + `ReplayEngine(...).run()`；逐 bar `begin_bar → 结算资金费 → match → end_bar → 记权益 → guard → on_bar`；成交可同 bar 回调策略（`runner.py:65-71`、`engine.py:105-172`） | `kind="replay"`；`meta{symbol,params,generated_at,duration_s,bars,start,end}`；`summary`=stats+`final_position/strategy_state/bars/start/end`；`equity{points≤1200,sampled_from,first,last}`；`drawdown{points≤900}`；`months[{month,ret,dd,trades,fees,funding,halted}]`；`fills≤5000{ts,side,qty,price,fee,tag,liquidity,client_id}`；`fills_truncated`；`orders{counts,rejection_reasons≤8,open≤60}`（`api/service.py:466-565`） |
| walkforward | 按月切片（`>=min_days×1440` 根），每月重置本金/锚点/库存跑 replay；`progress(done/total)`（`runner.py:74-142`） | `kind="walkforward"`；`meta` 加 `min_days`；`summary{months,total_return,mean,median,worst,best,positive,stops}`；`rows[{month,ret,dd,trades,fees,funding,halted}]`；`cumulative[[epoch秒,累计%]]`（`service.py:568-597`） |
| sweep | 笛卡尔积组合（runner 默认 12 组；CLI 18 组；面板可配 ≤48），逐组 replay；`progress(combo)`（`runner.py:145-183`、`api/app.py:152-157`） | `kind="sweep"`；`meta` 加 `axes`；`summary{combos,best,worst,positive}`；`rows[{spacing_bp,levels,leverage,ann_return,total_return,sharpe,max_dd,trades,fees,funding,halted}]`（`service.py:600-626`） |

- 绩效指标 `compute_stats`：`total_return`、`ann_return`（跨度/365.25）、`max_dd`、`sharpe`（日收益×√365）、`final_equity`、`trades`、`fees`、`funding`、`funding_pct_of_capital`、`turnover_x`、`avg_inventory_pct`、`halted`（`metrics.py:9-52`）。
- **边界（重要）**：`research/cli.py` 只解析参数并打印（replay 打印 summary JSON、可选 `--equity-out` CSV；walkforward/sweep 打印文本表），**没有 artifact、进度回调或取消**（`cli.py:60-140`）。
- artifact/进度/取消都在 API 层：`service.py` 打包 artifact，`jobs.py` 用 2 个 worker 线程执行并把进度写 SQLite，`store.py` 存 gzip JSON；cancel 置 `cancel_requested=1`，job 在每次 `progress()` 时检查并抛 `JobCanceled`（`jobs.py:65-127`、`store.py:163-170,189-199`）。
- **replay 运行中不可取消**：`run_replay` 是一次性调用，仅在 0.05/0.12/0.82/0.95 四个进度点检查取消；sweep 在组合之间、walkforward 在月份之间可取消（`service.py:312-373`、`runner.py:113-114,181-182`）。
