# GOOGLUSDT minute-grid backtest: fill bug, funding-sign fix, and no deployable edge

对 GOOGLUSDT（USDⓈ-M TRADIFI_PERPETUAL）1m 数据（2026-03-26..2026-11-16，235 天，337,778 根，718 次资金费结算）做分钟级网格回测。结论仍是：**不存在可部署的正期望**。但此前"所有静态配置都止损"的说法有一部分是资金费符号错误造成的，必须更正。

**Bug 1（成交价）**：旧模型用 target = -floor((P-anchor)/step) 逐边界调仓，向下跨越时把回补价记低一整格，价格在边界抖动一次就白赚一个 step。1m 噪声下约 46 次/天、10,918 笔/235 天；合成随机游走 +90.5%±6.9%/60 天。改为状态机（相邻格各挂一单，high/low 必须真正到达价格，上涨 bar 只卖、下跌 bar 只买）后，随机游走回到 +1.45%±1.31%/60 天，120bp 配置 467 笔。

**Bug 2（资金费符号，2026-11-16 修复）**：旧脚本按 `abs(pos) * price * rate` 计费，永远把资金费当成本。Binance 规则是正费率时多头付、空头收，正确记账为 `cash -= pos * price * rate`。修复后新旧引擎的成交笔数、手续费完全一致，差异只剩资金费（旧 `Config(120,30,0.5, stop_dd=9.9)` 由 +3.33% 变为 +8.73%），互为校验。新引擎结果与旧脚本相差 0.11pp 以内（止损成交时点与 mark 取价不同）。

**修正后的真实数据**：
- 静态全程锚点 120bp/30格/0.5x，10% 止损：累计 +8.62%（年化 +13.74%），最大回撤 9.75%，646 笔，手续费 $27.9，资金费**净收** $256，未触发止损。旧引擎同配置 +8.73%，交叉验证通过。
- 但这是刀锋结果：同一配置止损 2%/3%/5% 分别为 -1.94%/-2.93%/-5.36%，全部止损；只有 10% 止损这一档活下来。收益符号由止损阈值决定，不是 edge。
- 月度再定锚 + 10% 止损：120bp/30/0.5x 累计 -6.07%，月均 -0.67%，中位 +0.28%，最差 2026-04 -6.62%，正收益月 6/9，无止损；60bp/20/1x 累计 -5.48%，4 月 -9.79%、10 月 -8.93% 两次止损。
- 止损收紧到 2% 后年化最好的 +0.16%~+1.75% 仍是从 60+ 组参数里挑出的噪声；乐观 intrabar 仍为负（60bp -5.2%/年，120bp -13.6%/年）；7/14/30 天再定锚全部为负。
- 合成零漂移 GBM 对照（新引擎，5 条 20 天路径）：-1.12%~+0.19%，均值约 -0.4%，无造钱迹象。

**解释**：静态 +8.62% 的来源是"锚在 288、4 月 +33% 上涨中一路做空、回撤 9.75% 没被打掉、之后价格回落到 295 得以回补"，本质是一笔方向性空头库存押注，资金费净收（$256，占本金 2.6%）只是让它多活了 25bp 才没触发 10% 止损。资金费率均值 +0.009367%/8h（年化 10.26%）、中位 0，空头库存确实能收 carry，但代价是趋势月被库存打死。月度再定锚（不赌单一路径）仍然为负，因此结论不变。

**成本结构**：40~180 笔/月，手续费 $3~30/月，资金费 -$40~+$56/月（符号随库存方向）。主要亏损来自单向库存/趋势，不是手续费；排序仍为 库存/趋势 >> 手续费 > 资金费。

**建议**：不要在 GOOGLUSDT 上部署分钟级网格。基础设施可以建，策略应转向有信息优势的方向（美股/期货与 Binance perp 的 lead-lag、开盘/收盘/宏观事件，或带对冲的基差/资金费 carry）。若坚持网格，只能小资金/纸面，且不要用"刚好活过止损"的配置当证据。

复现：`gridtrade` 包（`python -m gridtrade.research.cli replay|walkforward|sweep`，52 个测试通过）；旧脚本 `research/backtest.py` 已修正资金费符号；数据 `research/data/GOOGLUSDT_1m.parquet`、`_funding.parquet`。

## Details

模型边界：仅 1m bar，无法还原盘中路径；保守规则（单边极值）低估成交与风险，intrabar 为乐观上界；235 天、单标的、单 regime（上市初期大波动），9 个月度样本不足以估计 Sharpe。资金费在结算时刻所在 bar 的开盘价、按上一 bar 收盘持仓结算，仍是对真实结算的近似（差异 <0.05pp）。3G/4C/4GB 服务器跑该链路资源充足，瓶颈是策略而非硬件。
