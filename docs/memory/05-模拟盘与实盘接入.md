## 速读（TL;DR）

- 模拟盘引擎在 `src/gridtrade/api/paper.py`，**无交易所凭据、只调 Gate 公开行情，永不下单**（`paper.py:1-10`、`paper.py:145-177`）。
- 多标的共享一个现金池与保证金上限：成交前校验 `gross + |qty|×price ≤ max(0,equity)×leverage ×1.0001`（`paper.py:419-423`）。
- 每个标的独立网格：`anchor + (level∓1)×step` 挂买卖各一单，标记价触达即按挂单价以 **maker** 费率纸面成交（`paper.py:200-207`、`paper.py:403-417`）。
- 费率优先取合约返回的 `maker_fee_rate/taker_fee_rate`（负值即返佣），缺失才回退 `.env` 的 bp 配置（`paper.py:425-433`、`paper.py:586-589`）。
- 资金费按 `funding_next_apply` 结算，费率取 Gate funding 历史中 ±15 分钟内最近一条，公式 `cash -= position×mark×rate`（`paper.py:477-509`）。
- 组合回撤超 `stop_dd_pct` → 全部按 taker 平仓、`status="halted"`、写 `last_error`（`paper.py:520-538`）。
- 实盘：Gate APIv4 `HMAC_SHA512(secret, method\npath\nquery\nsha512(body)\ntimestamp)`；下单默认锁定，`GRIDTRADE_LIVE_TRADING=0` 时写接口 403（`live_gate.py:131-137`、`live_gate.py:514-519`）。
- `/admin` 与面板令牌完全独立：账号密码 + PBKDF2（200k 轮）+ 内存会话 + Cookie `gt_admin`（`admin.py:28-48`、`admin.py:101-130`）。

### 1.3 网格与成交规则

| 项 | 公式/规则 | 证据 |
| --- | --- | --- |
| 层级 | `level = int(round(-position / unit))`（`unit<=0` 时返回 `(mark, mark)`） | `paper.py:200-203` |
| 买价 | `_round_to(anchor + (level-1)*step, tick_size)` | `paper.py:200-207` |
| 卖价 | `_round_to(anchor + (level+1)*step, tick_size)` | `paper.py:200-207` |
| 每格数量 | `budget = capital × leverage / max(1, 标的数 × max(1, levels))`；`unit = floor_to(budget/mark, mult)`，不足 `min_qty` 抬到 `min_qty` | `paper.py:567`、`paper.py:583-585` |
| 间距 | `step = round_to(mark × spacing_bp / 1e4, tick)`；`step < tick` → `ValueError("{symbol} 间距 Xbp 小于最小价格变动 Y")` | `paper.py:580-582` |
| 每标的合约参数 | `tick=order_price_round`（默认 0.01）、`mult=quanto_multiplier`（默认 0.01）、`min_qty=max(mult, order_size_min×mult)` | `paper.py:577-579` |
| 锚点 | `anchor = mark`（`_open` 时刻的标记价；只有 reset/重建会重锚） | `paper.py:597` |
| 持仓上限 | `max_position = unit × levels` | `paper.py:406` |
| 买单成交 | `mark <= buy + 1e-9` 且 `position + unit <= max_position + 1e-9` | `paper.py:409-410` |
| 卖单成交 | `mark >= sell - 1e-9` 且 `position - unit >= -max_position - 1e-9` | `paper.py:411-412` |
| 单 tick 撮合上限 | 最多 `_FILL_LIMIT = 200` 次循环；保证金不足立即 `return`（该标的本轮停止撮合） | `paper.py:28`、`paper.py:406-416` |
| 成交价 | 按挂单价（maker），不看盘口/滑点 | `paper.py:417` |

### 1.4 共享保证金

```python
cap = max(0.0, self.equity) * self.config.leverage          # 组合可用总名义
projected = self.gross + abs(qty) * price                   # 现有总名义 + 本次新增
return projected <= cap * 1.0001 + _EPS                     # 1e-9 容差，允许 1bp 余量
```

- 证据：`paper.py:419-423`；`gross = Σ |position| × mark`（`paper.py:511-512`）；`equity = cash + Σ unrealized`（`paper.py:514-518`）。
- 校验发生在**每笔成交前**；不通过则本轮不再为该标的撮合（`paper.py:415-416`）。
- 各标的初始预算相同（`capital×leverage/(标的数×levels)`），成交后按实际占用动态分配，没有权重/风险平价机制（`paper.py:567`）。
- 共享的是“总名义上限”，不是逐标的保证金；一个标的占用多了，其它标的会更早被 `_has_margin` 拒绝。

## 2. 实盘 live_gate

### 2.1 签名与错误类型

```python
payload   = hashlib.sha512(body.encode("utf-8")).hexdigest()
message   = f"{method}\n{path}\n{query}\n{payload}\n{timestamp}"
signature = hmac.new(secret.encode(), message.encode(), hashlib.sha512).hexdigest()
headers   = {"KEY": key, "Timestamp": timestamp, "SIGN": signature}
```

- `query = urlencode(sorted(params.items()))`（键排序），`timestamp = str(time.time())`（秒级浮点），`body` 为 `json.dumps(body)` 或 `""`（`live_gate.py:139-158`）。
- 客户端：`httpx.Client(base_url="https://api.gateio.ws/api/v4", timeout=8s/connect 5s)`（`live_gate.py:27`、`live_gate.py:118-126`）。
- 响应处理：`status>=400` 时优先取 JSON 的 `message`/`label`；`401/403` 统一抛 `LiveUpstream(..., 401)`；其它抛 `LiveUpstream("Gate 返回 {code}: …")`（502）；网络异常 502（`live_gate.py:159-170`）。

| 异常 | 默认消息 | HTTP |
| --- | --- | --- |
| `LiveDisabled` | `实盘未启用或未配置 API Key` / `实盘未启用` | 409 |
| `LiveLocked` | `实盘下单已锁定（GRIDTRADE_LIVE_TRADING=0）` | 403 |
| `LiveRejected` | 调用方给出（风控/参数） | 422 |
| `LiveUpstream` | Gate 网络/业务错误 | 502（鉴权失败 401） |

证据：`live_gate.py:31-54`；API 层映射见 `app.py:689-693`。

### 2.6 下单总开关锁定行为

| 入口 | 受 `GRIDTRADE_LIVE_TRADING=0` 限制 | 证据 |
| --- | --- | --- |
| `POST /api/live/orders` | 是（403 `LiveLocked`） | `live_gate.py:517-518`、`app.py:767-784` |
| `DELETE /api/live/orders/{id}` | 是（403） | `live_gate.py:589-591` |
| `POST /api/live/positions/{contract}/close` | 是（403） | `live_gate.py:593-595` |

| 开启前置条件 | `confirm_trading=true`（否则 400）；`cfg.configured`（否则 400） | `app.py:741-750` |

`GRIDTRADE_LIVE_ENABLED=0` 时会先命中 409（`LiveDisabled("实盘未启用")`），不是 403——两个开关的失败码不同（`live_gate.py:514-519`）。本机实测：未配置 Key 时 `POST /api/live/orders` 返回 `409 {"detail":"实盘未启用"}`；已启用且 Key 就绪、仅总锁为 0 时才是 `403 {"detail":"实盘下单已锁定（GRIDTRADE_LIVE_TRADING=0）"}`。

### 2.7 env 原子写回

`write_env_file(path, updates)`（`live_gate.py:83-112`）：

- 读旧文件 → 保留注释、空行、无 `=` 行与未涉及的键；命中的键值为 `None` 时**删除该行**；新键追加到末尾。
- 写 `path + ".tmp"` → `chmod(0o600)` → `os.replace(tmp, path)`（原子替换）。
- 值不做转义/引号处理；若写入含换行的值会破坏文件结构（当前调用方只写单行值）。
