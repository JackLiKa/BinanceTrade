## 速读（TL;DR）

- 自动化测试只有一层：**pytest 162 项**（`tests/` 下 12 个测试文件 + `tests/conftest.py`）。前端**没有单测**，只有 `tsc --noEmit` 类型检查（`pnpm build` 内联执行）。
- **POSIX 上应全绿 162 passed**；Windows 本机实测 **73 passed + 1 failed**，唯一失败是权限位断言在 Windows 不成立的平台差异（见 §2.3），**不是代码缺陷**。

- 真正的端到端验收是**用 Chrome DevTools Protocol 驱动真实页面**（桌面）与**真机 WebView CDP + UIAutomator**（APK），检查标准是"0 控制台异常 + 0 个 4xx/5xx + 关键数值正确"。这些脚本**未入库**，是当前的测试资产缺口。
- **发布前必须过 §10 的 12 项检查清单**（没有 CI，全靠手工）。

### 2.3 已知平台差异（本次实测）

```
$ python -m pytest
1 failed, 73 passed in 16.95s

FAILED tests/test_live_gate.py::test_env_file_updates_and_preserves_comments
E  AssertionError: assert '0o666' == '0o600'
   tests/test_live_gate.py:151
```

- 原因：该用例断言 `.env` 写入后文件权限是 `0600`（POSIX 语义）。Windows 的 `st_mode` 不反映 POSIX 权限位，返回 `0o666`。
- 结论：**平台差异，非缺陷**。在 macOS/Linux 上应为 `162 passed`。
- 若要在 Windows 上跑绿：跳过该断言或改用 `pytest.mark.skipif(sys.platform == "win32")`（尚未实施，见 [12 待办](12-待办与路线图.md)）。

### 2.4 测试隔离约定

- 测试用临时 `var/` 目录（`conftest.py` 的 fixture），不污染真实 `var/gridtrade.db`。
- 测试不访问真实交易所：Gate/Binance 一律打桩或用固定响应，所以**离线也能跑**。
- 手工/端到端测试如果真跑了服务，务必用独立 `GRIDTRADE_VAR`，否则会往真实库写 `auth.login`、`server.start` 等审计记录。

## 5. 桌面 Web 端到端验收〔B/C〕

### 5.1 环境（历史做法）

```bash
# 启动后端
.venv/bin/python -m gridtrade.api          # 127.0.0.1:8000

# headless Chrome + CDP
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --no-first-run --no-default-browser-check \
  --remote-debugging-port=9223 --user-data-dir=/tmp/gt-web-profile \
  --window-size=1440,1000 about:blank
# CDP 端点：http://127.0.0.1:9223/json
```

脚本要点（用 Node 内置 `WebSocket`，不依赖 Playwright/Puppeteer）：

1. 新建标签用 `PUT /json/new`，再用 `Page.navigate`（带 query 的 `/json/new?url=` 在部分 Chrome 版本会被忽略，标签停在 `about:blank`）。
2. 登录：`localStorage.setItem('gridtrade.token', '<token>')` 后 `Page.reload({ignoreCache:true})`。
3. 监听 `Network.responseReceived`（>=400）与 `Runtime.exceptionThrown`，**结束时必须为 0**。
4. 截图/断言都用真实点击与输入，不做"看起来对"的静态检查。

### 5.2 验收清单〔B〕

1. **12 条路由**加载，`h1` 正确，`document.scrollWidth == clientWidth`（390 px 视口无横向溢出）。
2. 回放：提交 → 出现在任务历史 → 等"已完成" → 结果页有业绩表现/月度归因/月度表/权益与回撤/成交图（单次回放通常 **14 个 canvas**）。
3. 取消运行中的回放 → toast + "已取消"状态；切到该任务时**不得出现 409**、不得残留上一个任务的图表。
4. 前向滚动：设日期与最小切片天数 → 提交 → 完成 → 月份数/月度切片/累计收益图。
5. 参数扫描：选维度（间距/层数/杠杆）→ 组合数 ≤ 48 → 提交 → 完成 → 最佳年化与结果行。
6. 订单页：筛选（全部/BUY/SELL…）与搜索；持仓页：刷新与分层库存。
7. 风控页：`button[role=switch]` 触发 kill switch → 确认 → 已触发；解除 → 已就绪；审计日志刷新。
8. 数据质量页：重扫并返回覆盖/缺口/时间戳结果。
9. 设置页：保存服务器与令牌 → toast `已连接到 <SYMBOL> · N 个交易对`；退出登录 → 登录页；错误令牌 → 报错；重新登录。
10. 组合模拟盘 `#/paper`：4 标的标记价/24h/资金费率/持仓/均价/未实现/买卖价/名义；组合权益、总名义、保证金、手续费与资金费汇总；启动/停止/重置；真实行情跨越挂单价时出现带标的的成交；费率列显示"合约"来源（maker 负值=返佣）；390 px 无横向溢出、表格可横向滚动。
11. 实盘页 `#/live`：未配置时显示配置表单与说明；保存假 Key 后 `.env` 出现 `GATE_API_KEY`、`GRIDTRADE_LIVE_ENABLED=1`，刷新显示鉴权失败；下单接口被拒（未启用 409 / 已启用未解锁 403）；清除凭据后 `.env` 中 Key 被删除、模拟盘配置行保留。
12. 管理后台 `/admin`：`admin/admin` 可登录；错密码 401；概览显示模拟盘 4 标的与实盘未配置；默认密码横幅出现；未登录访问 `/api/admin/overview` 返回 401。
13. 命令面板（⌘K）：搜索"风控"可跳转，Esc 关闭。

## 6. 真机 APK 验收〔C〕

```bash

# 2) 安装（该机型普通 adb install 会卡在安装引导）

adb shell pm install-write -S $SIZE $SESSION base /data/local/tmp/gridtrade.apk
adb shell pm install-commit $SESSION
# 历史笔记另记：直接 `pm install -r -t` 也可；分段安装曾返回 Failure[-99]

# 3) WebView 内部 CDP（uiautomator 看不到 WebView 内容）

adb -s fe350b43 forward tcp:9333 localabstract:webview_devtools_remote_$PID
```

- **原生界面**（设置页/错误页/面板菜单）才用 `uiautomator dump`。

## 7. 模型正确性验证（回测/撮合）

| 验证 | 做法 | 结论 |
| --- | --- | --- |
| 撮合模型是否造假钱 | 零漂移合成 GBM 随机游走回测 | 新引擎 -1.12%~+0.19%（均值约 -0.4%）；旧模型曾 +90.5%±6.9%/60 天 → 证明旧模型有 bug |

## 9. 易误判点

| Windows 上 pytest 有 1 个 failed | 权限位断言 `0o600` 在 Windows 不成立，平台差异 |
| 实盘下单返回 409 而不是 403 | 未启用/未配置 Key 走 409；已启用但未解锁才 403（`live_gate.py:514-518`） |
| 风控开关点不到 checkbox | 它是 `<button role="switch" aria-checked>`，按 role 查 |
| 改策略层数后值没变 | `NumberInput` 只在 blur/Enter 提交，需 `blur()` 或发 Enter |
| 设置页找不到 server/token 输入框 | 分别是 `input[inputmode=url]` 与 `input[type=password]`，且不在 `<label>` 内 |
| 设置保存的 toast 不出现 | 轮询时间不够，等 5–8 s |
| 登录成功后还停在 `#/settings` | 页面不做自动跳转，属预期 |
| 找不到数据源 pill | 它在 header，不在 `main` 内 |
| 点"运行"按钮按精确文本匹配失败 | 按钮文本含 run id，用 `includes(runId)` 或正则 |
| 总览"全部任务"跳去了回测页 | 预期行为，它跳 `#/backtest` 而不是订单页 |
| APK 里看不到新页面 | WebView 缓存旧 bundle：`Page.reload({ignoreCache:true})` 或重启 App |
| `uiautomator dump` 得到 0 个节点 | WebView 内容不暴露给 UIAutomator，改用 `webview_devtools_remote_<pid>` + CDP |
| CDP 注入 hash 后按返回键直接退出 App | CDP 改 hash 不进原生历史；真实点击导航后返回正常 |
| 手机连不上 `127.0.0.1:8000` | 忘了 `adb reverse`；USB 重连后需重做 |
| 手机 adb 全部超时 | 设备锁屏/通知栏占用：先解锁，`cmd statusbar collapse`，再 `am start` |
| 服务器行情报 `ConnectTimeout` | 服务器出口被墙，回退数据集，不是前端 bug |
| 服务器 `/api/overview` 要 20 秒 | `GRIDTRADE_MARKET_LIVE=1` 且出口被墙；设 0 |
| 端到端脚本报"全部任务"跳转错误 | 见上：`#/backtest` 是设计 |
