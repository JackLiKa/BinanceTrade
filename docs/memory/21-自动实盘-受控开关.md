# 21 自动实盘：节点执行 + 手动 ARM 开关

> 2026-11-18 · 真实资金受控版本

## 开关

- Web/APK 共用：`#/auto-live`
- 默认 **关闭**
- 每次进程重启自动回到关闭
- 必须输入 `ARM` 确认；再经过节点 `BINANCE_TRADING=1`、KILL 文件不存在
- 面板/节点都不保存 Binance Secret 到前端

## 执行

- 节点侧 `AutoLive` 线程
- 初始放入最多一买一卖两个 POST_ONLY（GTX）限价单
- 成交后根据仓位重算相邻网格；库存超出上限停止加仓
- 触发日亏损/回撤限制：撤掉自动单并停止（不自动市价平仓）
- 只撤 `gtal` 前缀订单，手工订单不动
- 每格名义 <5U、超过单笔/持仓上限时拒绝开启

## 风控字段

- capital / levels / leverage / spacing_bp
- max_order_notional
- max_position_notional
- stop_dd_pct + daily_loss_limit_pct
- poll_seconds

## 重要

- 当前真实账户约 15U，自动版会自动把层数压到能放下 5U 最小名义的组合
- 首版是简单相邻网格，不是高频做市
- 真实 maker 成交率、滑点、断线风险仍需模拟盘/小仓验证
