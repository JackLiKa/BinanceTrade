> **用途**：记录进程配置的全部来源（环境变量 / `.env`）、默认值、生效时机，以及三个 SQLite 库的表结构、运行期文件、备份与迁移规则。
> **读者**：部署与运维者、改配置或数据库相关代码的开发者；联调“为什么这个值没生效”时先看本文。
> **最后核实**：2026-11-17 · 代码基线 `9a5cc4f` · 事实均标注 `路径:行号`
> **相关文档**：[README 索引](README.md) · [03 接口参考](03-接口参考.md) · [05 模拟盘与实盘接入](05-模拟盘与实盘接入.md)
> **可信度**：A（已对照当前代码核实）；本机实测差异见第 8 节

## 速读（TL;DR）

- 配置只有两个来源：**真实环境变量优先**，其次仓库根 `.env`（`os.environ.setdefault`，不覆盖已有值）（`src/gridtrade/api/config.py:63-87`）。
- `.env` 路径顺序：`GRIDTRADE_ENV_FILE` → 当前工作目录（含 `pyproject.toml` 或 `src/gridtrade`）→ `REPO_ROOT/.env`（`config.py:46-60`）。
- 代码共读取 **37 行 / 38 个环境变量名**（`GRIDTRADE_PAPER_SYMBOLS` 与单数 `GRIDTRADE_PAPER_SYMBOL` 合一行）（`config.py:224-244`、`config.py:106-115`）。
- **默认值有版本差异**：`PaperConfig` 的 dataclass 默认是 `enabled=False/autostart=False`，但 `PaperConfig.from_env()` 默认 `True`（`config.py:122-123` vs `config.py:141-142`）；README 写 0，`.env.example` 写 1。
- 运行期有 **3 个 SQLite**：`var/gridtrade.db`（研究任务）、`var/paper.db`（模拟盘）、`var/admin.db`（后台账号）；**只有 `gridtrade.db` 设了 WAL**（`store.py:85-87`）。
- 研究产物是 `gridtrade.db.artifacts.payload` 里的 gzip BLOB，**不落磁盘文件**（`store.py:189-199`）。
- 改 `.env` 需重启；通过 API/后台写配置会同时更新内存对象，立即生效（`app.py:751-754`、`admin.py:233-236`、`admin.py:267-271`）。

## 1. 配置加载与生效

### 1.1 env 文件解析顺序

`Settings.from_env()` 第一行就调用无参的 `load_env_file()`，因此路径解析发生在任何变量读取之前（`config.py:224-225`）。

| 优先级 | 条件 | 使用的文件 | 证据 |
| --- | --- | --- | --- |
| 1 | `GRIDTRADE_ENV_FILE` 非空 | `Path(该值)`（相对路径按进程 cwd 解析） | `config.py:54-56` |
| 2 | `Path.cwd()/pyproject.toml` 是文件，或 `Path.cwd()/src/gridtrade` 是目录 | `cwd/.env`（systemd `WorkingDirectory` 即部署根） | `config.py:57-59` |
| 3 | 以上都不满足 | `REPO_ROOT/.env`，`REPO_ROOT = Path(__file__).resolve().parents[3]`（非 editable 安装时会指向 site-packages） | `config.py:16`、`config.py:60` |
| — | 文件不存在 | 返回 `None`，不报错、不生成文件 | `config.py:70-71` |

### 1.2 解析规则

| 规则 | 事实 | 证据 |
| --- | --- | --- |
| 覆盖语义 | `os.environ.setdefault(key, value)`：**真实环境变量优先**，`.env` 不覆盖已有值 | `config.py:86` |
| 跳过 | 空行、`#` 开头行、不含 `=` 的行 | `config.py:73-79` |
| `export` 前缀 | `export KEY=VALUE` 会去掉前缀后继续解析 | `config.py:76-77` |
| 分隔 | 按**第一个** `=` 切分（值里可含 `=`） | `config.py:78-80` |
| 空白与引号 | 键值均 `strip()`；值两侧同为 `'` 或 `"` 时去掉引号 | `config.py:81-84` |
| 类型 | 文件本身不做类型校验；读取时按变量各自的 `_as_float`/`_as_int`/`_env_bool` 解析，非法值静默回退默认 | `config.py:19-43` |
| 布尔 | 缺省→默认；`strip().lower()` 属于 `{"0","false","no","off"}` → False，其余（含 `"0.0"`）→ True | `config.py:39-43` |

### 1.3 生效时机

| 变更方式 | 生效范围 | 证据 |
| --- | --- | --- |
| 手工编辑 `.env` / 修改环境变量 | **必须重启进程**；`Settings.from_env()` 只在启动时调用一次（`__main__.py:12`），uvicorn 单进程 | `__main__.py:12-18`、`config.py:224` |
| `POST /api/live/config` | 写 `.env` 的同时更新 `settings.live` 与 `live_service.update_config()`（关旧客户端、清缓存）→ 立即生效 | `app.py:751-754` |
| `POST /api/admin/live` | 同上（后台路径） | `admin.py:233-236` |
| `POST /api/admin/paper` | 写 `.env` → `settings.paper = replace(...)` → `paper.reset(overrides)`；**会立即重置模拟盘账户** | `admin.py:267-271` |
| `POST /api/admin/token/rotate` | 覆盖 `var/token` + 写 `.env` + 更新 `settings.token` → 旧令牌立即失效（后台会话不受影响） | `admin.py:290-298` |
| `GRIDTRADE_SECURE_COOKIE` 等 | 只影响此后的 `Set-Cookie`，已下发 Cookie 不回收 | `app.py:381-389` |
| 启动时遗留任务清理 | 受 `GRIDTRADE_AUTORUN` 控制，只在 lifespan 启动阶段执行 | `app.py:265-268` |

## 4. SQLite 存储

### 4.1 三个数据库

| 数据库 | 路径 | 内容 | WAL | 连接方式 | 建表代码 |
| --- | --- | --- | --- | --- | --- |
| 研究库 | `{var_dir}/gridtrade.db` | runs / artifacts / settings / audit | **是**（`PRAGMA journal_mode=WAL`） | 每个方法新建连接，`timeout=10`，`Row` 工厂，成功后 `commit()`；写方法持 `threading.Lock` | `store.py:80-97` |
| 模拟盘库 | `{var_dir}/paper.db` | paper_account / paper_symbols / paper_fills / paper_equity / paper_funding | 否 | 每次 `_connect()` 新建连接，`timeout=10`，`Row`；无统一 commit 包装；DDL 与建表在 `paper.py:30-98`，建表/迁移调用在 `paper.py:625-645` | `paper.py:30-98`、`paper.py:625-645` |
| 管理库 | `{var_dir}/admin.db` | admin_user（单行） | 否 | 每次新建连接，`timeout=10`，`Row`；写后显式 `commit()` | `admin.py:61-86`、`admin.py:169` |

### 4.2 研究库 `gridtrade.db`（`store.py:21-58`）

```sql
CREATE TABLE IF NOT EXISTS runs (id TEXT PRIMARY KEY, kind TEXT NOT NULL, symbol TEXT NOT NULL,
    status TEXT NOT NULL, created_at TEXT NOT NULL, started_at TEXT, finished_at TEXT,
    params TEXT NOT NULL, summary TEXT, error TEXT, progress REAL NOT NULL DEFAULT 0,
    message TEXT NOT NULL DEFAULT '', cancel_requested INTEGER NOT NULL DEFAULT 0);
CREATE INDEX IF NOT EXISTS runs_created ON runs(created_at DESC);
CREATE TABLE IF NOT EXISTS artifacts (run_id TEXT PRIMARY KEY, payload BLOB NOT NULL,
    bytes INTEGER NOT NULL, created_at TEXT NOT NULL);
CREATE TABLE IF NOT EXISTS settings (key TEXT PRIMARY KEY, value TEXT NOT NULL);
CREATE TABLE IF NOT EXISTS audit (id INTEGER PRIMARY KEY AUTOINCREMENT, ts TEXT NOT NULL,
    actor TEXT NOT NULL, action TEXT NOT NULL, detail TEXT NOT NULL);
```

| 行为 | 事实 | 证据 |
| --- | --- | --- |
| 迁移 | 无版本号、无 `ALTER`；只 `CREATE TABLE/INDEX IF NOT EXISTS` | `store.py:85-87` |
| run id | `%Y%m%dT%H%M%SZ` + `-` + `secrets.token_hex(3)`（如 `20261117T134100Z-a1b2c3`） | `store.py:76-77` |
| 时间 | UTC ISO 秒精度，末尾 `Z` | `store.py:72-73` |
| 产物 | `gzip.compress(json.dumps(..., separators=(",",":"), default=str), compresslevel=6)` → `artifacts.payload`；`bytes` 记录压缩后大小；`INSERT OR REPLACE` | `store.py:189-199` |
| 设置 | `ON CONFLICT(key) DO UPDATE SET value=excluded.value`；`get_bool` 真值 `{"1","true","yes","on"}` | `store.py:220-232` |
| 审计 | `audit(ts, actor, action, detail)`，`actor` 默认 `"local"`；查询 `ORDER BY id DESC`，`limit` 钳制 1–500 | `store.py:234-247` |
| 保留策略 | 无自动清理；审计与产物只增不减 | `store.py`（无 DELETE） |

### 4.3 模拟盘库 `paper.db`（`paper.py:30-98`）

CREATE TABLE IF NOT EXISTS paper_account (id INTEGER PRIMARY KEY CHECK (id = 1), status TEXT NOT NULL,
    config TEXT NOT NULL, cash REAL NOT NULL, realized REAL NOT NULL DEFAULT 0,
    fees REAL NOT NULL DEFAULT 0, funding REAL NOT NULL DEFAULT 0, peak_equity REAL NOT NULL,
    started_at TEXT, updated_at TEXT, last_error TEXT, equity REAL NOT NULL DEFAULT 0,
    gross REAL NOT NULL DEFAULT 0);
CREATE TABLE IF NOT EXISTS paper_symbols (symbol TEXT PRIMARY KEY, mark REAL NOT NULL DEFAULT 0,
    index_price REAL NOT NULL DEFAULT 0, change_pct REAL, funding_rate REAL NOT NULL DEFAULT 0,
    anchor REAL NOT NULL DEFAULT 0, step REAL NOT NULL DEFAULT 0, unit REAL NOT NULL DEFAULT 0,
    tick_size REAL NOT NULL DEFAULT 0.01, step_size REAL NOT NULL DEFAULT 0.01,
    min_qty REAL NOT NULL DEFAULT 0.01, position REAL NOT NULL DEFAULT 0,
    avg_entry REAL NOT NULL DEFAULT 0, maker_fee REAL, taker_fee REAL, funding_next INTEGER,
    funding_interval INTEGER NOT NULL DEFAULT 28800);
CREATE TABLE IF NOT EXISTS paper_fills (id INTEGER PRIMARY KEY AUTOINCREMENT, ts TEXT NOT NULL,
    symbol TEXT NOT NULL, side TEXT NOT NULL, price REAL NOT NULL, qty REAL NOT NULL,
    fee REAL NOT NULL, realized REAL NOT NULL, reason TEXT NOT NULL);
CREATE INDEX IF NOT EXISTS paper_fills_ts ON paper_fills(id DESC);
CREATE TABLE IF NOT EXISTS paper_equity (id INTEGER PRIMARY KEY AUTOINCREMENT, ts TEXT NOT NULL,
    equity REAL NOT NULL, gross REAL NOT NULL, drawdown REAL NOT NULL);
CREATE INDEX IF NOT EXISTS paper_equity_ts ON paper_equity(id DESC);
CREATE TABLE IF NOT EXISTS paper_funding (id INTEGER PRIMARY KEY AUTOINCREMENT, ts TEXT NOT NULL,
    symbol TEXT NOT NULL, rate REAL NOT NULL, payment REAL NOT NULL, position REAL NOT NULL,
    mark REAL NOT NULL);

| 增量迁移 | 对 `paper_symbols` 检查 `PRAGMA table_info`，缺 `maker_fee`/`taker_fee` 时 `ALTER TABLE ... ADD COLUMN ... REAL` | `paper.py:641-644` |

## 7. 备份、迁移与安全

| 项 | 做法/事实 | 证据 |
| --- | --- | --- |
| 备份清单 | `var/`（`gridtrade.db`、`paper.db`、`admin.db`、`token`）+ `.env`；`research/data/` 可重抓、`web/dist/` 可重建 | `store.py:21-58`、`paper.py:225-252`、`admin.py:34-42` |
| 迁移（换机） | 拷 `var/` 与 `.env` 后重启即可；令牌可直接沿用 `var/token`，或用 `GRIDTRADE_TOKEN` 固定 | `config.py:90-103` |
| v1→v2 | `paper.db` 旧单标的库启动时自动重建，旧成交不保留（不可逆，重建前先备份） | `paper.py:630-645` |
| 令牌轮换 | **必须同时处理两处**，否则旧令牌继续有效：`.env` 里的 `GRIDTRADE_TOKEN` 优先级最高（`config.py:91-93`），只删 `var/token` 重启会**继续沿用环境变量里的旧令牌**。做法：① 用 `/admin` 的"轮换令牌"（覆盖 `var/token` + 写 `.env` + 更新 `settings.token`，旧令牌立即失效）；或 ② 手工删 `var/token` **并**删除/清空 `.env` 的 `GRIDTRADE_TOKEN`，再重启生成新令牌 | `config.py:90-103`、`admin.py:290-298` |
| 权限与边界 | `var/token` 与 API 写出的 `.env` 均为 `0600`；`.env` 含 Gate Secret，禁止入库/贴出；明文 HTTP 下 Cookie 与凭据可被截获；后台默认密码 `admin/admin` 必须修改；后台会话存内存，重启即失效 | `config.py:102`、`live_gate.py:111`、`app.py:381-389`、`admin.py:31-32`、`admin.py:65` |
