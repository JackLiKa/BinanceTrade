# 04 测试手册

**重点：所有验证都尽量走真实交互与真实 API，不做“看起来对”的静态检查。** 本次 Web 与真机测试均用 Chrome DevTools Protocol（CDP）驱动真实页面，覆盖提交任务、等待产物、点击、输入、开关与错误路径。

## 1. 环境

### 后端

```bash
cd /Users/user/Dev/bnapi
.venv/bin/python -m gridtrade.api          # 127.0.0.1:8000
curl -s localhost:8000/api/health
.venv/bin/python -m pytest                 # 最近一次 53 passed
```

### 桌面 Web 测试（headless Chrome）

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --no-first-run --no-default-browser-check \
  --remote-debugging-port=9223 --user-data-dir=/tmp/gt-web-profile \
  --window-size=1440,1000 about:blank
```

- CDP 端点：`http://127.0.0.1:9223/json`
- 页面地址：`http://127.0.0.1:8000`
- 建立新标签：`PUT /json/new`，随后用 `Page.navigate`（带 query 的 `/json/new?url=` 在部分版本会被忽略，标签停在 `about:blank`）。
- 登录：`localStorage.setItem('gridtrade.token', '<token>')` 后 `Page.reload({ignoreCache:true})`。令牌在 `var/token`。
- 监听 `Network.responseReceived`（>=400）与 `Runtime.exceptionThrown`，测试结束必须为 0（允许的已知噪声除外）。

### 真机 APK

- 设备：OnePlus PJA110（`fe350b43`），Android 16，1240×2772，density 560（约 354 CSS px）。
- 让手机访问本机后端：`adb -s fe350b43 reverse tcp:8000 tcp:8000`，APK 内服务器填 `http://127.0.0.1:8000`。
- 安装（该机型普通 `adb install` 会卡住）：

```bash
adb push apk/gridtrade.apk /data/local/tmp/gridtrade.apk
SIZE=$(stat -f%z apk/gridtrade.apk)
SESSION=$(adb shell pm install-create -r -t -S $SIZE | grep -oE '[0-9]+' | tail -1)
adb shell pm install-write -S $SIZE $SESSION base /data/local/tmp/gridtrade.apk
adb shell pm install-commit $SESSION
```

- **WebView 内部 CDP**（`uiautomator dump` 在 WebView 内容上只返回空节点）：

```bash
PID=$(adb -s fe350b43 shell pidof com.gridtrade.panel)
adb -s fe350b43 forward tcp:9333 localabstract:webview_devtools_remote_$PID
curl -s http://127.0.0.1:9333/json
```

- 原生界面（设置页/错误页/菜单）才用 `uiautomator dump`。
- 修改前端后需重新 `pnpm build`，再 `Page.reload({ignoreCache:true})`；APK 本身不必重装。

## 4. 易误判点（本次实际踩过）

| 现象 | 原因与正确做法 |
| --- | --- |
| 测试报“全部任务”跳转错误 | 总览的“全部任务”跳到 `#/backtest`，不是订单页 |
| APK 里看不到新页面 | WebView 缓存了旧 `index.html`/bundle；用 CDP `Page.reload({ignoreCache:true})` 或重启 App，必要时 `location.replace('/?v='+Date.now())` |
| 手机 `adb` 全部超时 | 设备锁屏/通知栏占用或 App 被切后台；先解锁并 `cmd statusbar collapse`，再 `am start` |
| 备用机装不上 APK | 该机 API 25 < minSdk 26；需 API 26+ 设备 |
| 修改策略层数后值没变 | `NumberInput` 只在 blur/Enter 提交；设置后要 `blur()` 或发送 Enter |
| 风控开关点不到 checkbox | 它是 `<button role="switch" aria-checked>`，按 role 查 |
| 找不到数据源 pill | pill 在 header，不在 `main` 内 |
| 点击运行按钮按精确文本失败 | 按钮文本含状态，改为 `includes(runId)` 或正则 |
| 设置页 server/token 输入框找不到 | 分别是 `input[inputmode=url]` 与 `input[type=password]`，且不在 `<label>` 内 |
| 设置保存 toast 没出现 | 轮询时间不够；等待 5–8 秒 |
| 登录成功后仍停在 `#/settings` | 页面不做自动跳转，属预期 |
| `uiautomator dump` 0 个节点 | WebView 内容不暴露给 UIAutomator，改用 WebView CDP |
| CDP 注入 hash 后按返回键直接退出 | CDP 的 hash 变更未计入 WebView 原生历史；真实点击导航后返回正常。原生返回逻辑已在 `onBackPressed` 处理 |
| 真机安装卡住 | OPPO/OnePlus 安装引导；用 `pm install-create/write/commit` |
| 手机连不上 `127.0.0.1:8000` | 忘了 `adb reverse`；USB 重连后需重做 |
| WebView 打开后是旧页面 | `Page.reload({ignoreCache:true})`；确认 `web/dist` 已重建 |
| 服务器上行情报 `ConnectTimeout` | 服务器出口访问不了 Binance，回退数据集，不是前端 bug |
