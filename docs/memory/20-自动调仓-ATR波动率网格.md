# 20 自动调仓：ATR 间距 + 波动率杠杆（自适应网格）

> 2026-11-18 · 研究/回测模式 · 测试 182 项

## 目标

不再手工猜网格间距/杠杆，按公开交易书籍的通用规则滚动调整：

| 规则 | 来源 | 实现 |
| --- | --- | --- |
| 用 ATR 缩放网格间距 | Wilder ATR / Ernest Chan 均值回归 | `spacing = clamp(1.2 × ATR/price × 10000, 40, 300) bp` |
| 波动率目标控制杠杆 | Robert Carver《Systematic Trading》 | `leverage = min(user_leverage, max(0.3, target_vol / realized_vol))` |
| 库存过高先平再重锚 | 库存/风险重置 | 间距变化 ≥15% 且持仓 > 半格时先 flatten；否则不频繁重锚 |
| 滚动重估、不用未来数据 | Pardo walk-forward | 每 `auto_interval` 根 K 线用过去 `auto_atr_window` 根计算 |
| 波动率目标 | 默认 25% 年化 | 可配 `auto_target_vol` |

## 使用

回测页参数面板打开：

```text
自动调参（ATR/波动率）
```

可选参数：

- 调参间隔：默认 1440 根（1 天）
- ATR 窗口：默认 120 根
- 目标年化波动：默认 25%

开启后，初始间距/杠杆只作为上限，系统会滚动调整。

## 边界

- 这是**回测/研究模式**，还没有自动接入实盘下单
- 自动调整会提高换手和成交数；真实 maker 成交率仍需打折
- 自动模式不是“自动赚钱”：GOOGL 90 天实测仍为亏损，只是减少了人工调参
- 波动率目标不是收益保证，趋势中仍会亏损
- 参数来自通用规则，不是针对某个标的优化出来的“圣杯”
