## 7. Binance 实盘 Plan B（详细方案）〔B〕

> 背景：广州服务器无法访问 `fapi.binance.com`（DNS 污染 + SNI 阻断，见 [07 §11.1](07-部署与运维.md#111-服务器访问不到-binance根因已定位)）；Binance 又禁止通过匿名代理访问其服务。所以"面板在国内 + 执行节点在境外"是唯一合规且可落地的结构。

**分工**

| 角色 | 做什么 |
| --- | --- |
| 用户 | 购买**东京 Lightsail**（当前价目：1GB 套餐约 **$5–7/月**，Ubuntu 24.04；见 §7.1）；提供 SSH；防火墙只放 22/51820 且仅允许 `81.71.71.131`；创建 Binance 合约**测试网** Key；确认风控上限 |
| 开发 | WireGuard 隧道（`10.66.0.1` / `10.66.0.2`）；东京执行节点（只监听内网 8100，持有 Key，强制风控）；Binance 合约适配器（签名/下单/撤单/对账/手续费/资金费）；面板接入（`provider=binance-node`，默认锁定）；先测试网验证再切真实 |

### 7.1 服务器选型：Lightsail 东京 vs EC2 东京（2026-11 结论）

**结论：执行节点用 Lightsail 东京 1GB；只有面板也要迁东京时才升到 Lightsail 2GB/4GB。EC2 留到"必须用 VPC/安全组/IAM/SSM/Spot/预留实例/Unlimited CPU"时再上。**

理由一句话：本项目节点**长期低 CPU、低流量、只要一台**，Lightsail 把"计算 + 磁盘 + 2TB 流量 + 公网 IPv4"打包成一个可预测月费；EC2 的同等规格要**按件叠加**（实例 + 公网 IPv4 $3.65/月 + EBS），小机器上附加费占比极高，且没有 Spot/预留时比 Lightsail 贵 **1.6–2×**。

| 项目（东京，2026-11 公开价目核对） | Lightsail 东京 | EC2 东京（t4g，arm64，按需） |
| --- | --- | --- |
| 1GB 档 / 月 | **约 $7 全包**（2 vCPU / 40GB SSD / 2TB 流量 / 含 IPv4） | t4g.micro ≈ $6.1–7 + **IPv4 $3.65** + EBS 30GB ≈ $3 ≈ **$13** |
| 2GB 档 / 月 | **约 $12 全包**（60GB / 3TB） | t4g.small ≈ $12.3–14 + $3.65 + $3 ≈ **$19–21** |
| 4GB 档 / 月 | **$24 全包**（2 vCPU / 80GB / 4TB） | t4g.medium ≈ $24.5–28 + $3.65 + $3 ≈ **$31–35** |
| 流量 | 2–4TB 额度（入+出都计入），日本超额 $0.14/GB | 入站免费；出站约 $0.114/GB（每月 100GB 免费额度） |
| 公网 IP | 静态 IP 附着时免费 | 每个公网 IPv4 **$0.005/h = $3.65/月**（含弹性 IP） |
| CPU 模型 | 突发型（基线约 5–10%，**无 Unlimited 模式**），持续高负载会降频 | t3/t4g 突发型，可开 **Unlimited**（超额另计费） |
| 停止计费 | **停止仍按月计费**，删掉才停 | 停止不计实例费；EBS/IP/快照继续计费 |
| 网络与权限 | 只有简易防火墙；不能挂 IAM Role；VPC 只能对等默认 VPC | 安全组、私有子网、IAM Role、SSM Session Manager（可不暴露 22）、CloudWatch 告警+自动恢复 |
| 省成本手段 | 无 RI/Spot/ Savings Plans | 1 年 Savings Plans 约 −30%；Spot 约 −50~70%（可被回收） |
| 升级/迁移 | 快照可**导出成 EC2 实例** | 换实例类型即可（Arm↔x86 需换 AMI） |
| 运维复杂度 | 低（控制台 5 分钟起一台） | 中（VPC/EBS/SG/AMI 都要自己拼） |

**两条容易被忽略的钱**：

- EC2 的**公网 IPv4 单独收费**（$3.65/月）——对 $6 的 t4g.micro 来说附加费占比 60%，这也是 Lightsail 在 1GB 档几乎必胜的原因。
- Lightsail **停止实例仍然收费**（官方计费 FAQ），别指望"关机省钱"；EC2 反而可以随时 stop 省钱。

**什么情况下改选 EC2**：

1. 需要把执行节点放进已有 VPC、用安全组/私有子网做网络分区；
2. 需要 IAM Role 让节点读 S3/Secrets Manager 而不落地密钥（合规）；
3. 需要 SSM Session Manager 完全不开 22 端口；
4. 需要 CloudWatch 告警 + 自动恢复（无人值守的交易节点很实际）；
5. 需要 Spot/预留把长期成本压到 Lightsail 以下（通常要 ≥2GB 才明显）；
6. CPU 长期 >20%（Lightsail 无 Unlimited，会被限频）。

**推荐落地形态**：

- 采购：Lightsail 东京、Ubuntu 24.04、1GB plan、静态 IP；开自动快照（保留 7 天，$0.05/GB·月）。
- 网络：防火墙只开 `22`（限你的 IP）与 `51820/udp`（仅 `81.71.71.131`）；**不要开 80/443**，面板仍留广州。
- 若日后面板也迁东京：用 Lightsail **2GB**（`pnpm build` 峰值内存约 1GB，1GB 会 OOM）。
- 出问题再迁：Lightsail 快照可导出 EC2；届时用 t4g.small + 1 年 Savings Plan + 安全组 + SSM。

参考：[Lightsail 价格](https://aws.amazon.com/lightsail/pricing/)（2026-10 核对：IPv4 套餐 $5 起、1GB 实测 $7、4GB $24）· [Lightsail 计费 FAQ](https://docs.aws.amazon.com/lightsail/latest/userguide/amazon-lightsail-frequently-asked-questions-faq-billing-and-account-management.html) · [EC2 实例价格 2026-10](https://www.logeshwaran.org/2026/10/ec2-instance-types-pricing.html)（t4g.micro $6.13/月、公网 IPv4 $3.65/月）· [Lightsail CPU 突发](https://docs.aws.amazon.com/lightsail/latest/userguide/cpu-burst-capacity-accrual.html)。

> 价格随时会变：**实际下单前用控制台/价格页核对东京区当前价**。另：AWS 免费层从 2025-07-15 起对**新账号**改为"$100 信用额 + 6 个月"，不要再按"t2/t3.micro 12 个月免费"做预算。

**其它备选（非 AWS，供比价）**：Vultr / Linode 东京 $5–6、Hetzner 新加坡 €5.49–5.99、腾讯云/阿里云新加坡或东京轻量；Oracle 免费层不稳定，不建议放交易节点。

**关键约束**

- 广州服务器可直连 `testnet.binancefuture.com`（历史实测 200、约 1.4 s），所以**测试网可以先用广州面板+测试网**做零成本验证。
- 先测试网、再真实；真实前必须有：订单对账、listenKey 续期、风控熔断、告警。
