## 8. 已知限制 / 风险

- 面板与后台均为 HTTP，密码/令牌明文；需尽快 HTTPS。
- 后台默认密码 `admin`，必须修改。
- APK 内嵌面板令牌；令牌轮换后需重打包。
- Binance 在服务器不可达；用代理访问违反 Binance《Prohibited Use Policy》；Binance 实盘需 Plan B（海外执行节点）。
- Binance 实盘适配器尚未实现；当前实盘仅 Gate。
- AMGN 流动性极低；模拟盘成交比真实盘口乐观。
- 模拟盘资金费为近似（最近费率+当前标记价）；无盘口/滑点模型。
