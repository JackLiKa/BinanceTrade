## 速读（TL;DR）

- 这是一个**单用户**的网格交易研究与面板系统：FastAPI 单体后端 + React SPA + Android WebView 壳，`src/gridtrade` 提供领域/策略/撮合/风控/研究/API 全部能力，Python 源码约 **5,400 行**，前端源码约 **7,100 行**。
- **三种运行形态同一套代码**：`#/overview` 等 **12 条 hash 路由**的 SPA（桌面侧边栏 / 移动底部导航），外加一个**独立的管理后台 `/admin`**（账号密码登录，与面板令牌完全分离）。
- **产品边界**：以研究回测与实时模拟盘为主；实盘（Gate USDT 永续）只做到"只读分析 + 下单代码完备但**默认硬锁**"（`GRIDTRADE_LIVE_TRADING=0`）。锁定时下单/撤单/平仓/杠杆会被拒，且是**两段式状态码**：未启用实盘或未配置 Key → **409**；已启用但未解锁 → **403**（`POST /api/live/config` 不受此锁约束）。
- **不接 Binance 私有接口**，行情侧只调官方公开接口（见 [11 外部接口清单](11-外部接口清单.md)），并由 `tests/test_external_endpoints.py` 白名单强制。
- **关键外部依赖**：研究数据来自 Binance USDⓈ-M 分钟 K 线（parquet，**不在仓库**）；实时模拟盘行情来自 **Gate.io** 公开 REST（因为部署服务器出口访问不到 `fapi.binance.com`）。
- **当前线上**：`http://81.71.71.131:8000`（Token 在服务器 `var/token`），明文 HTTP，**尚未上 HTTPS**——这是当前最高风险项。
- **最重要的一条研究结论**：GOOGLUSDT 分钟级网格**不存在可部署的正期望**，静态 +8.62% 是刀锋结果（详见 [09 策略研究结论](09-策略研究结论.md)）。不要重复在这条路上找 edge。
- 本仓库是**代码仓库**：令牌、行情数据、前端构建产物、APK 签名密钥都不在其中（见 §7）。

## 1. 项目定位与边界

**定位**：`gridtrade` 是一个面向"分钟级网格策略"的研究与验证平台，附带实时模拟盘和实盘只读分析。它不是一个通用交易终端，也不是多用户 SaaS。

| 维度 | 明确做什么 | 明确不做什么 |
| --- | --- | --- |
| 用户 | 单人，单令牌；**面板侧无用户表**（`/admin` 另有独立的 `admin_user` 表与账号体系） | 面板无注册、无权限分级、无租户隔离 |
| 研究 | 回放（replay）/ 前向滚动（walkforward）/ 参数扫描（sweep），确定性可复现 | 不做分布式回测、不做 tick 级、不做多品种组合优化 |
| 模拟盘 | 4 标的共享保证金组合网格，Gate 实时公开行情，成交/手续费/资金费落库 | 不建模盘口深度、不建模冲击成本、不下真实单 |
| 实盘 | Gate USDT 永续只读账户分析（权益/持仓/挂单/成交/流水/费率） | 下单默认锁定；Binance 实盘未实现；无订单对账、无 listenKey 续期 |
| 外部接口 | 只调官方公开接口，白名单测试强制 | 不用第三方聚合器/镜像作为生产数据源 |
| 密钥 | 只落在服务器 `.env`（0600）与 `var/` | 不进仓库、不经 API 回显 Secret |

三条"铁律"（任何改动都不要破坏）：

1. **实盘写操作默认锁定**：`GRIDTRADE_LIVE_TRADING=0` 时下单/撤单/平仓/杠杆一律被拒（未启用/未配置 **409**、已启用未解锁 **403**），且系统不会发出任何私有写请求。
2. **令牌等同全权限**：单因子认证，泄露即全权限。轮换要**同时**处理两处：删除 `var/token` **并且**清空 `.env` 里的 `GRIDTRADE_TOKEN`（环境变量优先级更高，只删文件不生效），重启后会生成新令牌；或直接用 `/admin` 的"轮换令牌"（它会把新令牌同时写进 `var/token` 与 `.env`）。
3. **新增外部接口必须三处同步**：源码、[11 外部接口清单](11-外部接口清单.md)、`tests/test_external_endpoints.py` 白名单，否则测试失败。

一个进程、一个端口同时提供 API、SPA、后台页；状态全部落本地 SQLite。所以**没有反向代理也能跑**，也**没有横向扩展能力**（见 [02 后端架构](02-后端架构与领域模型.md)）。

已登记标的（README 口径）：`GOOGLUSDT`、`SKHYUSDT`、`SPCXUSDT`、`AMGNUSDT`。页面顶部交易对下拉的选项数 = `research/data/*_1m.parquet` 的文件数。

GOOGLUSDT 数据集的历史口径（来自历史笔记，未在本机复核）：**2026-03-26 至 2026-11-16，约 235 天，337,778 根 1m K 线，718 次资金费结算，约 14MB，>1 分钟缺口 0**。
