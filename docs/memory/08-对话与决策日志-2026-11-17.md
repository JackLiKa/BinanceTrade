## 5. 手机首屏“加载不出来”

**排查**：手机网络正常（HTTP 200/99ms）；服务器无 OOM/重启；真正原因是 `/api/market/snapshot` 每次访问被墙的 Binance，连接超时把 `/api/overview` 拖到 **19–21 秒**。

**修复**：`GRIDTRADE_MARKET_LIVE=0`（服务器）、失败缓存 60s、连接 1.5s/总 3s、静态资源 gzip；overview 降到 **0.09–0.14s**。APK 本身 DOM 0.28s、PSS 116MB、掉帧 1.59%，不是瓶颈。提交 `bf1c415`。

## 7. Binance 不可达的原因与方案

**结论（实测）**：服务器在腾讯云广州；`fapi.binance.com` DNS 被污染（解析到 157.240.12.35、208.43.170.231 等伪造 IP）；即使用真实 CloudFront IP，TCP 443 能连但 TLS ClientHello 带 Binance SNI 被重置（errno 104）；80 也不通。GitHub 可通、Google/OKX/Bybit 也不通 —— 选择性网络封锁，不是服务器防火墙/安全组。

**方案**：
- 代码支持 `GRIDTRADE_PROXY`（HTTP CONNECT / SOCKS5，含 socksio），用本地 CONNECT 代理端到端验证 `source=binance`。
- 但 Binance《Prohibited Use Policy》明确禁止“匿名代理访问服务”，所以**不建议**用代理跑 Binance 账户/API；要么迁到可直连地区，要么用 Gate。
- 官方无 fapi 替代域名：`data-api.binance.vision` 仅现货，fapi 404。

**结论**：能。Gate USDT 永续支持 API 交易，服务器可直连；面板代码已具备只读+下单（锁定）。四个标的参数：1 张=0.01，maker -0.75bp、taker 7.5bp，8h 资金费；AMGN 流动性极低不建议实盘。

## 9. 独立管理后台（/admin）

**需求**：面板要独立后台，登录需要 account，账号密码预设 `admin`。

**方案**：`GET /admin` 独立页 + `/api/admin/*`；PBKDF2 存 `var/admin.db`；独立 `gt_admin` Cookie（12h，SameSite=Strict）；功能：概览、Gate 凭据/限额、模拟盘标的/参数、启停/重置、轮换面板令牌、改密、审计。默认 `admin/admin`，页面提示改密。提交 `20b5d91`。

## 10. Binance 放行香港 IP / 澳门身份资格

**香港 IP**：用 check-host 香港节点实测 `fapi.binance.com` 的 ping/premiumIndex/klines 均 200（CloudFront，约 65–100ms）——公开行情可访问；但 Binance 2021 公告限制香港用户的衍生品账户（账户层面）。

**澳门身份**：
- Binance 官方《List of Prohibited Countries》（2026-01-05）不含澳门；
- 《Terms of Use》2.1 要求 18+、非受限人员、使用地合法、不在禁止名单；2.3 允许按产品/地区追加限制；
- 香港衍生品公告只点名 Hong Kong，不涉及澳门；
- 用户确认“合约一直在用”，实际资格已通过。
- **但** Binance《Prohibited Use Policy》禁止匿名代理；用香港代理跑账户不合规。
