## 3. 2026-11-17 对话与决策日志

按"需求 → 结论/方案 → 落地"记录。这是理解"为什么选这条路"的第一手材料。

### 3.1 APK 免登录 + 实时模拟盘

- **需求**：APK 端不要登录，配置写到 `.env`；要一个实时模拟盘，记录收益/持仓，算手续费与资金费，数据从接口拿。
- **方案**：服务端新增 `.env` 加载（真实环境变量优先）；APK 构建时读 `apk/.env`（`SERVER_URL`/`TOKEN`）生成 `BuildConfig`，首启跳过设置页；服务器访问不了 Binance 合约接口但可访问 Gate USDT 永续，模拟盘改用 Gate 公开行情；`PaperEngine` 负责网格纸面成交、maker/taker 手续费、资金费结算、权益/持仓/成交落库 `var/paper.db`、重启恢复。
- **落地**：`d854812`。

### 3.2 四标的共享保证金组合

- **需求**：SKHYUSDT、SPCXUSDT、GOOGLUSDT、AMGNUSDT 做"混合模拟盘/实盘"，所有交易数据（资金费、手续费）都要算。
- **决策**：用户选择"共享保证金动态分配"，先只做模拟盘。Gate 对应 `SKHY_USDT/SPCX_USDT/GOOGL_USDT/AMGN_USDT`，四个都有永续。
- **方案**：重写为多标的组合——共享现金/权益，每标的独立网格，总名义受 `权益×杠杆` 约束；逐标的资金费/手续费；组合止损全平；SQLite 新表；组合视图页。
- **落地**：`caef2fa`；后续用 Gate 合约费率修正（§3.3）。

### 3.3 外部接口审计

- **需求**：确保所有接口都用记忆文档里列出的官方接口。
- **方案**：扫描源码，对照记忆库 Binance catalog 与 Gate 官方 SDK；新增外部接口清单文档与 `tests/test_external_endpoints.py`，未登记路径/非官方 host 直接失败。
- **附带修正**：Gate 合约返回 `maker_fee_rate=-0.000075`、`taker_fee_rate=0.00075`；模拟盘改为优先用交易所费率（负 maker=返佣），配置值仅回退。
- **落地**：`791f19f`。

### 3.4 Gate 实盘接入（只读 + 锁定下单）

- **需求**：接入实盘做实时分析；手动配置实盘信息，配置保存到 `.env`。
- **方案**：Gate 私有 API 只读分析（账户/持仓/挂单/成交/流水/费率）+ 下单/撤单/平仓/杠杆代码，但默认锁定（`GRIDTRADE_LIVE_TRADING=0`）；页面配置写 `.env`，Secret 不回显；下单前校验单笔/总名义/单标的/挂单数/权益倍数/紧急停止。
- **落地**：`c980d71`；随后修复非 editable 安装 `.env` 写错位置的问题。

### 3.5 手机首屏"加载不出来"

- **排查**：手机网络正常（HTTP 200/99ms）；服务器无 OOM/重启；真正原因是 `/api/market/snapshot` 每次访问被墙的 Binance，连接超时把 `/api/overview` 拖到 **19–21 秒**。
- **修复**：服务器 `GRIDTRADE_MARKET_LIVE=0`；失败缓存 60s；连接 1.5s/总 3s 超时；静态资源 gzip；overview 降到 **0.09–0.14s**。APK 本身 DOM 0.28s、PSS 116MB、掉帧 1.59%，不是瓶颈。
- **落地**：`bf1c415`。

### 3.6 切换其他代币合约

- **需求**：怎么切换其他合约。
- **方案**：研究页面的交易对下拉由 `research/data/*_1m.parquet` 决定。补抓并上传 SKHYUSDT/SPCXUSDT/AMGNUSDT 数据集（本地抓取，服务器无 Binance 出口），重启后顶部出现 4 个交易对；模拟盘组合由 `.env` 的 `GRIDTRADE_PAPER_SYMBOLS` 控制；实盘下单在 `#/live` 下拉选。
- **落地**：`275996c`。

### 3.7 Binance 不可达的原因

- **结论（实测）**：服务器在腾讯云广州；`fapi.binance.com` DNS 被污染（解析到 157.240.12.35、208.43.170.231 等伪造 IP）；即使指定真实 CloudFront IP，TLS ClientHello 带 Binance SNI 会被重置（`errno=104`）；80 端口也不通。GitHub 可通、Google/OKX/Bybit 也不通 → 选择性网络封锁，不是服务器防火墙/安全组。
- **方案**：代码支持 `GRIDTRADE_PROXY`（HTTP CONNECT / SOCKS5，含 socksio），本地用 CONNECT 代理验证 `source=binance`。但 Binance《Prohibited Use Policy》禁止匿名代理访问，所以**不建议用代理跑 Binance 账户/API**；要么迁到可直连地区，要么用 Gate。官方无 `fapi` 替代域名（`data-api.binance.vision` 仅现货，fapi 404）。
- **落地**：`7589bfd`（证据）、`d8cb139`（代理支持）。

### 3.8 Gate 能否做实盘

- **结论**：能。Gate USDT 永续支持 API 交易，服务器可直连；面板已具备只读+下单（锁定）。四标的参数：1 张=0.01，maker -0.75bp、taker 7.5bp，8h 资金费；AMGN 流动性极低不建议实盘。
- **入口**：Gate 网页 → 头像 → API 管理；App → 我的 → API 管理；合约账户需划转 USDT，建议单向持仓。

### 3.9 独立管理后台

- **需求**：面板要独立后台，登录需要 account，账号密码预设 `admin`。
- **方案**：`GET /admin` 独立页 + `/api/admin/*`；PBKDF2 存 `var/admin.db`；独立 `gt_admin` Cookie（12h，SameSite=Strict）；功能：概览、Gate 凭据/限额、模拟盘标的/参数、启停/重置、轮换面板令牌、改密、审计。
- **落地**：`20b5d91`。

### 3.10 Binance 香港 IP 与澳门身份

- **香港 IP**：check-host 香港节点实测 `fapi.binance.com` 的 ping/premiumIndex/klines 均 200（CloudFront，约 65–100ms）；但 Binance 2021 公告限制香港用户的衍生品账户（账户层面）。
- **澳门身份**：Binance《List of Prohibited Countries》（2026-01-05）不含澳门；《Terms of Use》2.1 要求 18+、非受限人员、使用地合法；2.3 允许按产品/地区追加限制；香港衍生品公告只点名 Hong Kong。用户确认"合约一直在用"。**但**《Prohibited Use Policy》禁止匿名代理，用香港代理跑账户不合规。
- **落地**：`3552b24`。

### 3.11 Binance 实盘与 Plan B

- **测试网**：广州服务器可直连 `testnet.binancefuture.com`（200，约 1.4s），可用于零成本验证下单/撤单/对账；真实 fapi 仍被墙。
- **三种落地**：A 面板迁新加坡/东京；B 保留广州面板 + 海外执行节点（**用户选择 B**）；C 只做 Binance 行情。
- **Plan B 分工**：详见 [12 §7](12-待办与路线图.md#7-binance-实盘-plan-b详细方案b)。

## 7. 归档原则

1. **原始笔记不改写**：`vault/` 是 DSH 记忆库的原始快照（含自动捕获的会话记录）。它们有历史价值，也可能过时——**以本套整理文档为准**，但不要删 vault。
2. **时间线只带时点**：任何"当前状态"的结论都要写"截至哪个提交/哪天"。旧文档最大的问题就是"数值无时点"。
3. **数字必须可回溯**：能由 `git log`、`pytest --collect-only`、OpenAPI schema 直接得到的，就写命令与结果；只有历史笔记才有的，标可信度 B/C。
4. **缺陷记录含根因与验证**：只写"修了 X"没有价值，要写"为什么错、怎么证明修好了"。
5. **文档变更要留痕**：重大重构（如本次 2026-11-17 重写）应在本文件记录"旧 → 新"的映射，避免读者拿旧文档对不上号。
