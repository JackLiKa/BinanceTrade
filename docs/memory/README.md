## 4. 换机器后的最小恢复步骤

**先看 [01 §7](01-项目总览.md#7-仓库里有--没有的东西)：仓库里没有 `web/dist`、`research/data`、`var/token`、`.env`、APK 签名密钥。**

```bash
# 1) 克隆
git clone https://github.com/JackLiKa/BinanceTrade.git
cd BinanceTrade

# 2) 后端（POSIX）
python3.12 -m venv .venv
.venv/bin/pip install -e '.[dev]'

#    Windows 副本的最小做法（已实测）：不装包也能跑，因为 pyproject 设了 pythonpath=["src"]
#    python -m pytest
#    $env:PYTHONPATH="src"; python -m gridtrade.api

# 3) 行情数据（仓库不含；需要能访问 fapi.binance.com 的网络）
.venv/bin/python research/fetch.py --symbol GOOGLUSDT

# 4) 前端（仓库不含 web/dist，必须构建）
pnpm --dir web install --frozen-lockfile
pnpm --dir web build          # 内含 tsc --noEmit

# 5) 启动
.venv/bin/python -m gridtrade.api
# 浏览器 http://127.0.0.1:8000 ，令牌在 var/token（首次启动自动生成，32 字符）
```

判读：`/api/health` 200 就说明服务起来了；**没有 `research/data/` 时研究类接口会返回 503 `no research datasets found`，这是预期行为**（见 [08 §4](08-测试与验收.md#4-本机最小可复现验证本次实测)）。

## 5. 五条"动手前必须知道"

1. **令牌 = 全权限**。泄露就删 `var/token` 重启（自动生成新令牌），或设 `GRIDTRADE_TOKEN`；轮换后旧浏览器/APK 会话失效。Google 登录单独走 `var/auth.db` 白名单，与令牌并存。
2. **实盘默认锁死**。`GRIDTRADE_LIVE_TRADING=0` 时不会发出任何真实订单；写接口返回 **409（未启用/未配置）/ 403（已启用未解锁）**。不要为了"测试"把它打开。
3. **`var/` 不可再生**。`gridtrade.db`（任务历史）、`paper.db`（模拟盘账户）、`admin.db`（后台账号）、`token` 都在里面；rsync `--delete` 或清理时**必须排除 `var/`**。
4. **不构建前端就没有页面**。后端只托管 `web/dist`；改完前端必须 `pnpm --dir web build`，APK 用户还要强刷。
5. **别再在分钟级网格上找 edge**。60+ 组参数扫过，结论是负期望（[09](09-策略研究结论.md)）。要改策略先读 §9 的边界。

## 6. 术语表

| 术语 | 含义 |
| --- | --- |
| 面板 / Panel | 本项目的 Web SPA（12 条 hash 路由），也泛指整个系统 |
| 后台 / `/admin` | 与面板令牌分离的独立管理页（账号密码 + PBKDF2 + `gt_admin` Cookie） |
| 研究 / research | 回测与数据相关功能（replay / walkforward / sweep、数据集、数据质量） |
| 任务 / run | 一次回放、前向滚动或参数扫描；异步执行，状态在 `var/gridtrade.db` |
| 产物 / artifact | 任务完成后写入 SQLite 的 JSON 结果（权益曲线、成交、月度行等），仅 `succeeded` 可取 |
| 模拟盘 / paper | 实时组合网格纸面交易，Gate 公开行情，状态在 `var/paper.db` |
| 实盘 / live | Gate USDT 永续真实账户；只读分析可用，下单默认锁定 |
| 网格 / grid | 在锚点上下按 `spacing_bp` 挂买卖单的策略；`levels` 为单边最大格数 |
| 锚点 / anchor | 网格中心价；静态锚点或按 N 根 K 线重锚（`reanchor_bars`） |
| bp | 万分之一（0.01%）；手续费/间距/滑点单位 |
| 资金费 / funding | 永续合约周期性多空互付；本项目 `cash -= pos × mark × rate` |
| 保守 / 乐观 intrabar | 只有 1m bar 时的两种成交口径；`--intrabar` 为乐观上界 |
| 共享保证金 | 多标的共用一个权益×杠杆上限，成交前校验总名义 |
| 数据源 pill | header 上的行情来源标记（binance / dataset / offline），判断"是不是实时"要看它 |
| DSH vault | `docs/memory/vault/` 下的原始记忆笔记（未改写） |
