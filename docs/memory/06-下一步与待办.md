## P0 — 部署收尾（需要用户决策）

### 1. 选择对外访问方式

- [ ] 域名 + HTTPS（推荐）：用户提供已解析到 `81.71.71.131` 的域名。
  - 安装 Caddy（或给现有 nginx 配 certbot），反代 `127.0.0.1:8000`。
  - 放行 ufw 443（当前仅 22/80/3010/3000），并确认云安全组放行 443。
  - systemd 增加 `GRIDTRADE_SECURE_COOKIE=1`，重启。
  - 验证：`https://<域名>/api/health`、登录、WebSocket、9 页、回放。
- [ ] 直接开放 `IP:8000`（HTTP）：改 `GRIDTRADE_HOST=0.0.0.0`，ufw + 云安全组放行 8000。**仅临时使用，令牌明文。**

### 2. APK 指向正式地址

- [ ] 地址确定后修改 `apk/src/com/gridtrade/panel/MainActivity.java:44` 的 `DEFAULT_SERVER`。

- [ ] 真机回归：首启设置页默认值、登录、9 页、回放、返回键菜单。
