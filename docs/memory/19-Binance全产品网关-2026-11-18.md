# 19 Binance 全产品网关 / 运行时 demo 清理

> 2026-11-18 · 测试 179 项

## 范围

- 产品：Spot / USDⓈ-M / COIN-M / Options / Wallet（只读）
- 读：通用 `GET` 官方 REST 路径
- 写：只允许订单/撤单/杠杆/持仓模式等交易控制路径
- 资金移动：**不在 Web/HTTP 网关中**，只允许服务器本地 `scripts/binance_cli.py`

## 实现

- `src/gridtrade/api/binance_gateway.py`
  - 产品 base URL：api / fapi / dapi / eapi
  - HMAC 签名、timestamp/recvWindow、`X-MBX-APIKEY`
  - 只读路径不限制具体官方 path；写路径白名单
  - `BLOCKED_PREFIXES` 拦截提现、划转、子账户、API Key 管理
  - 写操作要求 `BINANCE_TRADING=1` + `confirm=true` + KILL 文件不存在
- 节点：`POST /gateway`（仅 WireGuard 内网）
- 面板：`POST /api/binance/gateway` + `#/binance-api` 控制台
- 本地 CLI：`scripts/binance_cli.py`
  - `read` / `write` / `withdraw` / `transfer`
  - 资金命令必须 `--confirm` 且在终端输入 `YES`
  - 使用节点 venv 与 root 环境文件，不经面板

## Demo 清理

- `BinanceDemoConfig.base_url` 默认改为真实 `https://fapi.binance.com`
- 运行时不再默认连接 `demo-fapi.binance.com`
- 测试层 MockTransport 保留：它不是运行时假数据，删除会让 pytest 直接打真实交易所
- 东京节点环境已显式 `BINANCE_BASE_URL=https://fapi.binance.com`

## 本地 CLI 安装（东京节点）

```bash
sudo install -m 755 scripts/binance_cli.py /opt/gridtrade/binance_cli.py
sudo tee /usr/local/bin/binance-cli >/dev/null <<'SH'
#!/bin/sh
set -a; . /etc/binance/adapter.env; set +a
PYTHONPATH=/opt/gridtrade/app exec /opt/gridtrade/venv/bin/python /opt/gridtrade/binance_cli.py "$@"
SH
sudo chmod 755 /usr/local/bin/binance-cli
```

示例：

```bash
sudo binance-cli read --product usdm --path /fapi/v1/time
sudo binance-cli withdraw --coin USDT --address ... --amount 10 --network ETH --confirm
```

## 安全边界

- Web 网关永不接受提现/划转/子账户/API Key 管理
- 写接口默认 `BINANCE_TRADING=0`，需要服务器 root 显式开启
- 真正的提现仍需 API Key 提现权限 + IP 白名单 + 本地二次确认
