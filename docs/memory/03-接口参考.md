## 速读（TL;DR）

- 路由共 **48 个装饰器 / 47 条 HTTP + 1 条 WebSocket**：24 个 `GET`、22 个 `POST`、1 个 `DELETE`、1 个 `WS`，其中 `GET /admin` 与 SPA 兜底 `GET /{path:path}` 是 HTTP 但不在 OpenAPI schema 里（`src/gridtrade/api/app.py:367-958`）。FastAPI 导出的 OpenAPI 为 **44 个 path / 45 个 operation / 17 个 schema**（`docs/memory/_work/openapi.json`，OpenAPI 3.1.0，title=`Gridtrade Research API`，version=`0.1.0`；`app.py:287-293`）。
- 口径区分：44（OpenAPI path）+ `GET /admin` + `GET /{path:path}` + `WS /ws`（OpenAPI 不含 WS）= 45 个 HTTP/WS 入口；再按 method 展开时 `/api/live/config` 同时有 GET/POST，故 OpenAPI 为 44 path / 45 operation。
- 只有两种认证依赖：`guarded = [Depends(require_token)]`（面板令牌）与 `admin_guarded = [Depends(require_admin)]`（后台会话 Cookie `gt_admin`）（`app.py:353`、`app.py:362`）。
- 公开路由：`GET /api/health`、`POST /api/auth/login`、`POST /api/admin/login`、`GET /admin`、SPA 兜底；WS 在握手内部自行校验令牌（`app.py:909-912`）。FastAPI 文档 `/api/docs`、`/api/openapi.json` 也无认证（`app.py:291-292`）。
- 面板令牌三种传递：`Authorization: Bearer <token>`、`X-API-Token`、Cookie `gt_token`（30 天、httpOnly、SameSite=Lax）（`app.py:321-328`、`app.py:381-389`）。
- **全部路由未声明 `response_model`**；成功响应是动态 `dict`（少数为 `FileResponse`/`JSONResponse`），错误统一为 FastAPI 默认 `{"detail": ...}`。
- 三类研究任务 `POST /api/runs/{replay,walkforward,sweep}` 立即返回 `202` + `status="queued"` 的 run；产物只允许从 `succeeded` 任务取，否则 `409`（`app.py:562-575`）。
- WS 每 3 秒推一条 `{"type":"market",...}`，**只含行情快照，不含任务状态**（`app.py:921-931`）。

### 1.2 认证与令牌传递

| 方式 | 读取逻辑 | 适用 | 证据 |
| --- | --- | --- | --- |
| `Authorization: Bearer <token>` | `header[:7].lower() == "bearer "`，取 `header[7:].strip()` | 面板 | `app.py:322-324` |
| `X-API-Token: <token>` | `request.headers.get("x-api-token").strip()` | 面板 | `app.py:325-327` |
| Cookie `gt_token` | `request.cookies.get("gt_token")` | 面板；由 `POST /api/auth/login` 下发 | `app.py:328`、`app.py:381-389` |
| `?token=` | WS 握手优先用 query，其次 Cookie | `WS /ws` | `app.py:909` |
| Cookie `gt_admin` | `request.cookies.get("gt_admin")`，值须存在于内存会话表 | 后台 `/api/admin/*` | `app.py:355-360`、`admin.py:119-130` |

- 面板令牌比较使用 `hmac.compare_digest`，失败返回 `401 invalid or missing access token` + `WWW-Authenticate: Bearer`（`app.py:330-336`）。
- 后台未登录/过期返回 `401 管理员未登录或会话已过期`（`app.py:358-360`）。
- 面板登录 `401 invalid access token` 并写审计 `auth.failed`；成功则下发 Cookie 并写 `auth.login`（`app.py:376-395`）。
- 两套凭据**互不通用**：面板令牌不能访问 `/api/admin/*`，后台会话不能访问业务 API（`app.py:353`、`app.py:362`）。

### 1.3 数据集缺失时的降级

`resolve_symbol()` 会先调 `visible_symbols()`，数据集目录没有 `*_1m.parquet` 时直接 `503 no research datasets found`（`app.py:338-351`）。因此**数据集缺失只影响研究类接口**：

| 接口 | 无 `research/data/` 时 | 证据 |
| --- | --- | --- |
| `/api/session`、`/api/dataset/symbols`、`/api/dataset/quality`、`/api/market/snapshot`、`/api/overview`、`/api/settings`、`/api/risk` | **503** `{"detail":"no research datasets found"}` | `app.py:344`（这些路由都先走 `resolve_symbol()`/`visible_symbols()`） |
| `/api/runs`、`/api/runs/{id}`、`/api/audit` | 200（不解析标的） | `app.py:547-585`、`app.py:897-899` |
| `/api/paper`、`/api/paper/*` | 200（模拟盘只用 Gate 行情与 `var/paper.db`） | `app.py:802-832` |
| `/api/live*`、`/api/admin/*` | 200（实盘/后台不依赖数据集） | `app.py:695-798`、`app.py:591-685` |
| `GET /api/health` | 200，`symbols: []` | `app.py:367-374` |

本机实测（Windows，`PYTHONPATH=src python -m gridtrade.api`，无 `research/data/`）与上表一致；此时 `/api/market/snapshot` 不会走到 `source="offline"` 回退，因为标的解析先失败。

## 4. 任务状态机与产物

| --- | --- | --- |
